> These are existing editor templates; their Spine library depends on the editor version. For the Engine 2.0 runtime, see [Using in Code](/en/docs/graphics/2D/spine/add-and-use) and the [3.8](https://github.com/galacean/engine/blob/dev/2.0/examples/src/spine-otakugirl-3.8.ts) and [4.2](https://github.com/galacean/engine/blob/dev/2.0/examples/src/spine-keli-4.2.ts) source examples. The dynamic partial skin replacement template uses the old library's native atlas/attachment API, which is not part of the new public interface.

The Galacean editor provides a series of tutorial examples to help you quickly get started with Spine animations.  
After entering the [Editor](https://galacean.antgroup.com/editor/projects), click the **Templates** tab on the left to view them.
