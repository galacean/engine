### Limit Velocity Over Lifetime Module

[`LimitVelocityOverLifetimeModule`](/apis/core/#LimitVelocityOverLifetimeModule) inherits from `ParticleGeneratorModule` and is used to limit particle velocity over lifetime, with optional damping and drag when the velocity exceeds the configured limit.

Note that this module requires WebGL2. On WebGL1, enabling it will be silently ignored.

## Properties

| Property | Description |
| --- | --- |
| [separateAxes](/apis/core/#LimitVelocityOverLifetimeModule-separateAxes) | `boolean` value indicating whether to limit velocity per axis. When disabled, use `speed`; when enabled, use `speedX`, `speedY`, and `speedZ` |
| [speed](/apis/core/#LimitVelocityOverLifetimeModule-speed) | [ParticleCompositeCurve](/apis/core/#ParticleCompositeCurve) object representing the overall velocity limit when `separateAxes` is disabled |
| [speedX](/apis/core/#LimitVelocityOverLifetimeModule-speedX) | [ParticleCompositeCurve](/apis/core/#ParticleCompositeCurve) object representing the x-axis velocity limit; equivalent to `speed` when `separateAxes` is disabled |
| [speedY](/apis/core/#LimitVelocityOverLifetimeModule-speedY) | [ParticleCompositeCurve](/apis/core/#ParticleCompositeCurve) object representing the y-axis velocity limit |
| [speedZ](/apis/core/#LimitVelocityOverLifetimeModule-speedZ) | [ParticleCompositeCurve](/apis/core/#ParticleCompositeCurve) object representing the z-axis velocity limit |
| [dampen](/apis/core/#LimitVelocityOverLifetimeModule-dampen) | `number` value controlling how strongly excess velocity is damped, in the range `0 ~ 1`. Only takes effect when particle velocity exceeds the `speed` limit, reducing the excess portion proportionally; has no effect when velocity is within the limit |
| [drag](/apis/core/#LimitVelocityOverLifetimeModule-drag) | [ParticleCompositeCurve](/apis/core/#ParticleCompositeCurve) object representing a continuous drag coefficient applied to particle velocity. Unlike `dampen`, `drag` applies resistance continuously regardless of whether the velocity exceeds the limit |
| [multiplyDragByParticleSize](/apis/core/#LimitVelocityOverLifetimeModule-multiplyDragByParticleSize) | `boolean` value indicating whether to scale `drag` by particle size |
| [multiplyDragByParticleVelocity](/apis/core/#LimitVelocityOverLifetimeModule-multiplyDragByParticleVelocity) | `boolean` value indicating whether to scale `drag` by current particle velocity. When enabled, high-speed particles experience significantly more drag than low-speed ones |
| [space](/apis/core/#LimitVelocityOverLifetimeModule-space) | [`ParticleSimulationSpace`](/apis/core/#ParticleSimulationSpace) enum specifying the space used for limiting velocity; only effective when `separateAxes` is enabled. When `separateAxes` is disabled, the speed limit applies to the overall velocity magnitude, so switching `space` produces no visual difference; only when `separateAxes` is enabled does per-axis limiting make `space` switching visually noticeable |
