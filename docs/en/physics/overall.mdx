The physics engine is a core part of game runtime. Galacean exposes physics through the unified [Physics System API](https://github.com/galacean/engine/tree/main/packages/design/src/physics) and provides a built-in PhysX backend compiled through [PhysX.js](https://github.com/galacean/physX.js). For the overall design of the physics components, refer to the [Wiki](https://github.com/galacean/engine/wiki/Physical-system-design).

For scenarios that use physics components or `InputManager` raycast picking, initialize the physics backend before use:

- [physics-physx](https://github.com/galacean/engine/tree/main/packages/physics-physx)

Developers can set the physics backend in the **Project Settings** panel opened from the [Main Menu](/en/docs/interface/sidebar) interface.

## Script Usage

```typescript
import { WebGLEngine } from "@galacean/engine";
import { PhysXPhysics } from "@galacean/engine-physics-physx";

const engine = await WebGLEngine.create({
  canvas: htmlCanvas,
  physics: new PhysXPhysics()
});
```

The UMD, ESM, and CommonJS entries load the packaged runtime from `./libs/` beside the entry file. When self-hosting, copy `dist/libs/` alongside that file.

When upgrading to 2.0, change direct asset imports and CDN links from `@galacean/engine-physics-physx/libs/*` to `@galacean/engine-physics-physx/dist/libs/*`.

In Vite development, add `@galacean/engine-physics-physx` to `optimizeDeps.exclude` so the assets resolve relative to the package.

Dedicated module Workers and Node.js use the packaged `.mjs` loader by default. Web pages and classic Workers use the `.js` loader. A classic Worker loading UMD with `importScripts()` requires an explicit loader URL.

To host the runtime separately, set `wasmModeUrl` for standard WASM and `wasmSIMDModeUrl` for SIMD in the second constructor argument. Keep the `.wasm` from the same release beside its loader.

## Backend Notes

PhysX requires WebAssembly. `Auto` selects SIMD when supported and otherwise uses the standard build. Startup loads one JavaScript loader and its matching WASM binary, about 2.5 MiB for the standard build or 3.0 MiB for SIMD before compression.

| Feature                        | physics-physx |
| ------------------------------ | ------------- |
| Collision Detection            | Yes           |
| Physics Effects and Feedback   | Yes           |
| Continuous Collision Detection | Yes           |
| Joint System                   | Yes           |
