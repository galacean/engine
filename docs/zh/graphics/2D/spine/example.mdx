> 以下是现有编辑器模板，使用的 Spine 库随编辑器版本而定。Engine 2.0 的独立运行时用法见[添加与使用](/docs/graphics/2D/spine/add-and-use)，示例源码见 [3.8](https://github.com/galacean/engine/blob/dev/2.0/examples/src/spine-otakugirl-3.8.ts) 和 [4.2](https://github.com/galacean/engine/blob/dev/2.0/examples/src/spine-keli-4.2.ts)。其中“动态局部换肤”模板使用旧库原生 atlas/attachment API，不适用于新的公共接口。

Galacean 编辑器提供了一系列教学示例，帮助大家更快的上手 Spine 动画的使用。
进入[编辑器](https://galacean.antgroup.com/editor/projects) 后，你可以点击左侧的 Templates Tab 进入查看。
