## 脚本使用

目前提供的几何体如下：

- [createCuboid](/apis/core/#PrimitiveMesh-createCuboid) **立方体**

```typescript
const entity = rootEntity.createChild("cuboid");
entity.transform.setPosition(0, 1, 0);
const renderer = entity.addComponent(MeshRenderer);
renderer.mesh = PrimitiveMesh.createCuboid(engine);
// Create material
const material = new BlinnPhongMaterial(engine);
material.emissiveColor.set(1, 1, 1, 1);
renderer.setMaterial(material);
```

## 程序化几何

每个工厂方法接收一个具名配置对象。配置类型逐字段说明含义、单位和默认值；省略对象或其中的字段即可使用默认值。例如，`createSphere` 接收 `SphereMeshOptions`：

```ts
const unitSphere = PrimitiveMesh.createSphere(engine);
const sphere = PrimitiveMesh.createSphere(engine, { radius: 1 });
const smoothSphere = PrimitiveMesh.createSphere(engine, { radius: 1, subdivisions: 4 });

const cube = PrimitiveMesh.createCuboid(engine, { width: 2 });
const box = PrimitiveMesh.createCuboid(engine, { width: 2, height: 3, depth: 4 });
const ground = PrimitiveMesh.createPlane(engine, { width: 10 });

const cylinder = PrimitiveMesh.createCylinder(engine, { radius: 0.5, height: 2 });
const frustum = PrimitiveMesh.createTruncatedCone(engine, { topRadius: 0.25, bottomRadius: 0.5, height: 2 });
const mirroredKnot = PrimitiveMesh.createTorusKnot(engine, { radius: 1, tubeRadius: 0.1, p: 2, q: -3 });
```

`createCuboid` 的高度、深度默认等于宽度；`createPlane` 的高度默认等于宽度。平面和长方体的后续分段数默认沿用第一个方向的分段数。球体使用一个细分层级，默认为 3，限制在 1 到 6 之间。`createCylinder` 只有一个半径；上下半径不同的圆台使用 `createTruncatedCone`。`createRing` 的 `innerRadius` 默认等于 `outerRadius` 的一半。

尺寸、分段和网格设置都使用具名字段，可以只修改其中任意一项。

环面结的 `p`、`q` 是有符号整数缠绕次数，与网格分段数无关。负值反转对应方向的缠绕，`0` 表示该方向的角度保持不变。

| 能力 | 创建方法 |
| --- | --- |
| 平面、长方体、球 | `createPlane`、`createCuboid`、`createSphere` |
| 圆柱、圆台、圆锥、胶囊 | `createCylinder`、`createTruncatedCone`、`createCone`、`createCapsule` |
| 圆盘、圆环面、圆环体、环面结 | `createCircle`、`createRing`、`createTorus`、`createTorusKnot` |
| 四面体、八面体、二十面体、十二面体 | `createTetrahedron`、`createOctahedron`、`createIcosahedron`、`createDodecahedron` |
| 旋转体、路径管道、平面多边形、拉伸、圆角长方体 | `createLathe`、`createTube`、`createPolygon`、`createExtrusion`、`createRoundedCuboid` |

### 分段、角度和端盖

`createTube` 与 `createTorus` 的 `tubularSegments` 控制管道方向的分段，`radialSegments` 控制截面的周向分段。胶囊的 `capSegments` 独立控制每个半球从极点到赤道的分段，`height` 仍指圆柱部分的高度。

角度范围统一放在配置对象中。所有角度均使用**度数**，范围使用 `Vector2`，`x` 表示起始角，`y` 表示结束角。跨越 360 度时使用连续角度，例如 `new Vector2(350, 370)`。圆柱、圆锥和旋转体围绕 Y 轴，0 度从 +Z 方向开始；球体的垂直角度从 +Y 极点开始。

```ts
import { PrimitiveMeshCapMode, Vector2 } from "@galacean/engine";

const hemisphere = PrimitiveMesh.createSphere(engine, { verticalRange: new Vector2(0, 90), radius: 1 });
const openCylinder = PrimitiveMesh.createCylinder(engine, { caps: PrimitiveMeshCapMode.None, radius: 0.5, height: 2 });
const cupWall = PrimitiveMesh.createCylinder(engine, { caps: PrimitiveMeshCapMode.Bottom, radius: 0.5, height: 2 });
const halfRing = PrimitiveMesh.createRing(engine, { angleRange: new Vector2(0, 180), outerRadius: 1, innerRadius: 0.5 });
```

圆柱和圆台的 `caps` 使用 `PrimitiveMeshCapMode`：`Both`（默认）、`Top`、`Bottom`、`None`。顶盖朝 +Y，底盖朝 -Y，角度裁切产生的侧面切口保持开放。圆锥用布尔值 `cap` 控制底盖。`createCircle`、`createRing` 和多边形位于 XY 平面、正面朝 +Z；地面用的 `createPlane` 位于 XZ 平面、正面朝 +Y。

`createSphere` 将细分后的立方体投影到球面，支持 `horizontalRange` 和 `verticalRange`。水平角度从 -X 朝 +Z 开始，垂直角度从 +Y 极点开始。裁切保留细分表面，切口不生成端盖；水平范围 `new Vector2(350, 370)` 可跨越接缝。细分层级控制表面及裁切边界的精细程度。

### 轮廓与路径

轮廓和旋转体截面使用 `Vector2` 数组，路径点使用 `Vector3` 数组。一个简单多边形直接传入点数组；有孔洞时使用 `{ points, holes }`，多个多边形使用这种对象的数组。首尾点不必重复。

```ts
import { Vector2, Vector3 } from "@galacean/engine";

const outline = [new Vector2(-2, -2), new Vector2(2, -2), new Vector2(2, 2), new Vector2(-2, 2)];
const hole = [new Vector2(-1, -1), new Vector2(-1, 1), new Vector2(1, 1), new Vector2(1, -1)];
const face = PrimitiveMesh.createPolygon(engine, { points: outline, holes: [hole] });

const solid = PrimitiveMesh.createExtrusion(engine, { points: outline, holes: [hole] }, { depth: 0.5 });
const beveled = PrimitiveMesh.createExtrusion(engine, outline, {
  bevelSize: 0.05,
  bevelOffset: 0.02,
  depth: 0.5,
  steps: 1
});

const path = Array.from({ length: 65 }, (_, i) => {
  const t = i / 64;
  return new Vector3(4 * t, Math.sin(t * Math.PI * 2), 0);
});
const tube = PrimitiveMesh.createTube(engine, path, { radius: 0.1, tubularSegments: 64 });
const swept = PrimitiveMesh.createExtrusion(engine, outline, { path: path, steps: 64 });
const loop = [new Vector3(-4, 0, -4), new Vector3(4, 0, -4), new Vector3(4, 0, 4), new Vector3(-4, 0, 4)];
const closed = PrimitiveMesh.createExtrusion(engine, outline, { closed: true, path: loop, steps: 32 });
```

拉伸配置分为 `LinearExtrusionMeshOptions` 和 `PathExtrusionMeshOptions`：前者指定 `depth` 与倒角，后者必须指定 `path`。TypeScript 会拒绝同时传入路径与深度或倒角的组合。默认沿 +Z 直线拉伸且不倒角；`bevelSize > 0` 时开启倒角，`bevelThickness` 默认等于 `bevelSize`。沿路径拉伸不生成倒角。路径接收 `Vector3` 数组，并按折线长度均匀采样。使用曲线时，在外层采样成点数组后传入，如上例所示。

管道和路径挤出的 `closed` 默认关闭；开启后自动连接路径首尾并对齐截面，不必重复首点。闭合挤出至少使用三段，不生成端盖。开放挤出保留两端端盖；管道在两种模式下都不生成端盖。

`bevelOffset` 默认是 `0`，用于偏移侧壁轮廓：正值外扩实体并缩小孔洞，负值内缩实体并扩大孔洞。`bevelSize` 为 `0` 时偏移仍然生效。倒角从偏移后的轮廓向内削边，厚度包含在 `depth` 内，不会增加总厚度。

### 网格数据和材质

网格设置与尺寸、分段放在同一配置对象中：

```ts
const editable = PrimitiveMesh.createSphere(engine, { keepData: true, radius: 1, subdivisions: 3 });
const sixMaterials = PrimitiveMesh.createCuboid(engine, {
  separateMaterials: true,
  width: 1,
  height: 1,
  depth: 1,
  widthSegments: 1,
  heightSegments: 1,
  depthSegments: 1
});
```

`keepData` 默认关闭，设为 `true` 时保留可读的 CPU 顶点属性。

`separateMaterials` 适用于长方体、圆柱、圆台、圆锥、多边形、挤出和圆角长方体。默认关闭，生成一个 SubMesh；开启后，生成的 SubMesh 按以下顺序对应材质槽：

| 几何体             | 材质槽顺序                                                                   |
| ------------------ | ---------------------------------------------------------------------------- |
| 长方体、圆角长方体 | +Y、-Y、-X、+X、+Z、-Z                                                       |
| 圆柱、圆台         | 侧面、顶盖、底盖                                                             |
| 圆锥               | 侧面、底盖                                                                   |
| 多边形             | 按输入顺序，每个形状一个槽；孔洞与外轮廓共用该槽                             |
| 挤出               | 按输入形状顺序，端盖一个槽、侧壁和倒角一个槽；闭合路径每个形状只有一个侧壁槽 |

只有实际生成的部位占用槽位。关闭或半径为零的端盖不保留空槽，因此只有底盖的圆柱使用槽 0 绘制侧面、槽 1 绘制底盖。改变部位或形状后重建网格时，需要按新的槽位顺序更新材质数组。

通过 `renderer.setMaterials(materials)` 分配材质。如果所有槽使用同一个材质，可以传入 `mesh.subMeshes.map(() => material)`。

创建时会复制输入数据，修改原始点数组不会改变已创建的网格或其设备恢复结果。修改参数时重新创建网格即可。

### 可序列化的基础网格资产

`PrimitiveMeshAsset` 从 `@galacean/engine` 和 `@galacean/engine-loader` 导出，Editor 可以直接用它约束保存的 JSON：

```ts
import type { PrimitiveMeshAsset } from "@galacean/engine";

const asset = {
  type: "sphere",
  sphereOptions: { radius: 1, subdivisions: 3, keepData: true }
} satisfies PrimitiveMeshAsset;
```

每个 `type` 对应同名的 `PrimitiveMesh.createX` 方法，`<type>Options` 使用该工厂的具名字段和默认值。角度范围保存为 `{ x: 起始角, y: 结束角 }`，由 Loader 构造 `Vector2`。例如 `circleOptions: { angleRange: { x: 30, y: 180 } }` 创建从 30 度到 180 度的扇形。省略字段时采用创建 API 的默认值，包括由其他字段决定的默认值；角度仍使用度数。

| 资产类型 | 必填几何字段 |
| --- | --- |
| `sphere`、`cuboid`、`plane` | 无 |
| `cylinder`、`truncatedCone`、`cone`、`capsule` | 无 |
| `torus`、`circle`、`ring`、`torusKnot`、`roundedCuboid` | 无 |
| `tetrahedron`、`octahedron`、`icosahedron`、`dodecahedron` | 无 |
| `lathe` | `latheProfile` |
| `tube` | `tubePath` |
| `polygon` | `polygonShapes` |
| `extrusion` | `extrusionShapes`；可指定 `extrusionOptions.depth` 或 `extrusionOptions.path` |

`sphere` 创建立方体细分后投影得到的球体，`sphereOptions.subdivisions` 控制细分层级。`cylinder` 使用一个半径；`truncatedCone` 分别使用 `truncatedConeOptions.topRadius` 和 `truncatedConeOptions.bottomRadius`。

轮廓和旋转截面保存为 `{ x, y }` 点数组，路径保存为 `{ x, y, z }` 点数组，由 Loader 构造对应向量。多边形与拉伸统一使用形状数组，每个形状包含 `points` 和可选的 `holes`：

```json
{
  "type": "extrusion",
  "extrusionShapes": [
    {
      "points": [
        { "x": -2, "y": -2 },
        { "x": 2, "y": -2 },
        { "x": 2, "y": 2 },
        { "x": -2, "y": 2 }
      ],
      "holes": [
        [
          { "x": -1, "y": -1 },
          { "x": -1, "y": 1 },
          { "x": 1, "y": 1 },
          { "x": 1, "y": -1 }
        ]
      ]
    }
  ],
  "extrusionOptions": { "depth": 2, "bevelSize": 0.1, "bevelOffset": 0.2, "separateMaterials": true }
}
```

沿路径拉伸使用 `extrusionOptions.path` 替代 `extrusionOptions.depth`，不接受倒角选项。`extrusionOptions.closed` 设为 `true` 时闭合路径且不生成端盖。路径点保存为 `{ x, y, z }`。

以上类型前缀字段及 `<type>Options` 都能经过 Editor 现有的基础网格打包过滤。Editor 预览应使用与保存资产相同的创建方法和参数。
