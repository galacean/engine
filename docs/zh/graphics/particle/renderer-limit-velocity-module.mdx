### 生命周期限速模块

[`LimitVelocityOverLifetimeModule`](/apis/core/#LimitVelocityOverLifetimeModule) 继承自 `ParticleGeneratorModule`，用于在粒子生命周期内限制速度，并在超出上限时施加阻尼或拖拽效果。

<Image src="https://mdn.alipayobjects.com/huamei_9ahbho/afts/img/A*l6KuQ5Z-L4QAAAAAQjAAAAgAegDwAQ/original" alt="limit velocity" style={{ zoom: "50%" }} />

需要注意的是，该模块依赖 WebGL2；在 WebGL1 环境下，即使开启也会被忽略。

## 属性

| 属性 | 释义 |
| --- | --- |
| [separateAxes](/apis/core/#LimitVelocityOverLifetimeModule-separateAxes) | `boolean` 类型，是否分别限制各轴速度。关闭时使用 `speed`，开启时使用 `speedX`、`speedY`、`speedZ` |
| [speed](/apis/core/#LimitVelocityOverLifetimeModule-speed) | [ParticleCompositeCurve](/apis/core/#ParticleCompositeCurve) 对象，在 `separateAxes` 关闭时表示粒子的整体速度上限 |
| [speedX](/apis/core/#LimitVelocityOverLifetimeModule-speedX) | [ParticleCompositeCurve](/apis/core/#ParticleCompositeCurve) 对象，表示 x 轴速度上限；在 `separateAxes` 关闭时等同于 `speed` |
| [speedY](/apis/core/#LimitVelocityOverLifetimeModule-speedY) | [ParticleCompositeCurve](/apis/core/#ParticleCompositeCurve) 对象，表示 y 轴速度上限 |
| [speedZ](/apis/core/#LimitVelocityOverLifetimeModule-speedZ) | [ParticleCompositeCurve](/apis/core/#ParticleCompositeCurve) 对象，表示 z 轴速度上限 |
| [dampen](/apis/core/#LimitVelocityOverLifetimeModule-dampen) | `number` 类型，超出速度上限后施加的阻尼强度，取值范围为 `0 ~ 1`。仅当粒子速度超过 `speed` 定义的上限时才会介入，按比例削减超出部分；速度未超限时完全不生效 |
| [drag](/apis/core/#LimitVelocityOverLifetimeModule-drag) | [ParticleCompositeCurve](/apis/core/#ParticleCompositeCurve) 对象，表示持续作用于粒子速度的阻力系数。与 `dampen` 不同，`drag` 会持续对粒子施加阻力，无论速度是否超限 |
| [multiplyDragByParticleSize](/apis/core/#LimitVelocityOverLifetimeModule-multiplyDragByParticleSize) | `boolean` 类型，是否按粒子尺寸放大 `drag` 的影响 |
| [multiplyDragByParticleVelocity](/apis/core/#LimitVelocityOverLifetimeModule-multiplyDragByParticleVelocity) | `boolean` 类型，是否按粒子当前速度放大 `drag` 的影响。开启后，高速粒子受到的阻力远大于低速粒子 |
| [space](/apis/core/#LimitVelocityOverLifetimeModule-space) | [`ParticleSimulationSpace`](/apis/core/#ParticleSimulationSpace) 枚举，指定限速所使用的空间；仅在 `separateAxes` 开启时生效。当 `separateAxes` 关闭时，限速作用于整体速度大小，切换 `space` 不会有视觉上的差异；只有开启 `separateAxes` 后，各轴独立限速，`space` 的切换才会产生明显的视觉效果 |
