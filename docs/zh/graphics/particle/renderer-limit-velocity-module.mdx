### 生命周期限速模块

[`LimitVelocityOverLifetimeModule`](/apis/core/#LimitVelocityOverLifetimeModule) 继承自 `ParticleGeneratorModule`，用于在粒子生命周期内限制速度，并在超出上限时施加阻尼或拖拽效果。

需要注意的是，该模块依赖 WebGL2；在 WebGL1 环境下，即使开启也会被忽略。

## 属性

| 属性 | 释义 |
| --- | --- |
| [separateAxes](/apis/core/#LimitVelocityOverLifetimeModule-separateAxes) | `boolean` 类型，是否分别限制各轴速度。关闭时使用 `speed`，开启时使用 `speedX`、`speedY`、`speedZ` |
| [speed](/apis/core/#LimitVelocityOverLifetimeModule-speed) | [ParticleCompositeCurve](/apis/core/#ParticleCompositeCurve) 对象，在 `separateAxes` 关闭时表示粒子的整体速度上限 |
| [speedX](/apis/core/#LimitVelocityOverLifetimeModule-speedX) | [ParticleCompositeCurve](/apis/core/#ParticleCompositeCurve) 对象，表示 x 轴速度上限；在 `separateAxes` 关闭时等同于 `speed` |
| [speedY](/apis/core/#LimitVelocityOverLifetimeModule-speedY) | [ParticleCompositeCurve](/apis/core/#ParticleCompositeCurve) 对象，表示 y 轴速度上限 |
| [speedZ](/apis/core/#LimitVelocityOverLifetimeModule-speedZ) | [ParticleCompositeCurve](/apis/core/#ParticleCompositeCurve) 对象，表示 z 轴速度上限 |
| [dampen](/apis/core/#LimitVelocityOverLifetimeModule-dampen) | `number` 类型，超出速度上限后施加的阻尼强度，取值范围为 `0 ~ 1` |
| [drag](/apis/core/#LimitVelocityOverLifetimeModule-drag) | [ParticleCompositeCurve](/apis/core/#ParticleCompositeCurve) 对象，表示生命周期内对粒子速度施加的拖拽系数 |
| [multiplyDragByParticleSize](/apis/core/#LimitVelocityOverLifetimeModule-multiplyDragByParticleSize) | `boolean` 类型，是否按粒子尺寸放大 `drag` 的影响 |
| [multiplyDragByParticleVelocity](/apis/core/#LimitVelocityOverLifetimeModule-multiplyDragByParticleVelocity) | `boolean` 类型，是否按粒子当前速度放大 `drag` 的影响 |
| [space](/apis/core/#LimitVelocityOverLifetimeModule-space) | [`ParticleSimulationSpace`](/apis/core/#ParticleSimulationSpace) 枚举，指定限速所使用的空间；仅在 `separateAxes` 开启时生效 |

## 使用示例

下面的示例会在世界空间中分别限制粒子 x、y、z 方向的速度，并在超过上限时施加阻尼：

```ts
const { limitVelocityOverLifetime } = particleRenderer.generator;

limitVelocityOverLifetime.enabled = true;
limitVelocityOverLifetime.separateAxes = true;
limitVelocityOverLifetime.speedX = new ParticleCompositeCurve(1);
limitVelocityOverLifetime.speedY = new ParticleCompositeCurve(1);
limitVelocityOverLifetime.speedZ = new ParticleCompositeCurve(0);
limitVelocityOverLifetime.space = ParticleSimulationSpace.World;
limitVelocityOverLifetime.dampen = 0.25;
limitVelocityOverLifetime.drag = new ParticleCompositeCurve(0);
limitVelocityOverLifetime.multiplyDragByParticleSize = true;
limitVelocityOverLifetime.multiplyDragByParticleVelocity = true;
```

如果只需要限制粒子的整体速度，可以关闭 `separateAxes` 并直接设置 `speed`。
