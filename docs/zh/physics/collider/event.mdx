碰撞事件是物理系统的重要组成部分，允许脚本响应物体之间的物理交互。Galacean 物理系统提供了两种类型的事件：碰撞事件和触发器事件。

## 事件类型

### 碰撞事件
碰撞事件在两个处于碰撞器模式的碰撞器物理交互时触发。这些事件提供了关于碰撞的信息，如接触点、法线和涉及的另一个碰撞器。

### 触发器事件
触发器事件在碰撞器进入、停留或离开触发区域时触发。触发器是将 `isTrigger` 属性设置为 true 的碰撞器。它们检测重叠而不引起物理反应。

## 碰撞器模式 VS 触发器模式

| 模式 | 描述 | 使用场景 |
| ---- | ---- | -------- |
| **碰撞器模式** | 触发碰撞器事件，具有实际的物理碰撞效果 | 需要真实物理交互的物体 |
| **触发器模式** | 仅触发事件回调，不产生物理碰撞 | 检测区域、触发机关等 |

<Callout type="positive">
触发器模式按碰撞器组件单独设置。一个实体，或拥有多个碰撞器的刚体，可以同时具备两种模式：一部分碰撞器负责物理碰撞，另一部分设置 `isTrigger` 用于区域检测。
</Callout>

## 事件回调

当两个碰撞器发生碰撞或触发器重叠时，会调用每个碰撞器自身所在实体上挂载的[脚本](/docs/script/script)中的回调函数。子实体上的碰撞器只通知该子实体上的脚本，不会通知其刚体所在实体。

- 触发器回调接收 `(other, self)`：另一个碰撞器，以及本脚本所在实体上接收事件的碰撞器。
- 碰撞回调接收一个 [Collision](/apis/core/#Collision)：`collision.collider` 是另一个碰撞器，`collision.selfCollider` 是接收事件的碰撞器。`getContacts()` 返回的接触点法线和冲量从另一个碰撞器指向接收者。Collision 数据只在回调期间有效，需要保留的数据请自行复制。

### 碰撞器事件回调
| 事件名 | 触发时机 |
| --- | --- |
| [**onCollisionEnter**](/apis/core/#Script-onCollisionEnter) | 开始碰撞时触发 |
| [**onCollisionExit**](/apis/core/#Script-onCollisionExit) | 结束碰撞时触发 |
| [**onCollisionStay**](/apis/core/#Script-onCollisionStay) | 碰撞持续时触发 |

### 触发器事件回调
| 事件名 | 触发时机 |
| --- | --- |
| [**onTriggerEnter**](/apis/core/#Script-onTriggerEnter) | 进入触发器时触发 |
| [**onTriggerExit**](/apis/core/#Script-onTriggerExit) | 离开触发器时触发 |
| [**onTriggerStay**](/apis/core/#Script-onTriggerStay) | 在触发器内时持续触发 |

## 脚本使用

```typescript
import { Collider, Collision, ContactPoint, Script } from "@galacean/engine";

class EventHandler extends Script {
  private _contacts: ContactPoint[] = [];

  // 碰撞器事件
  onCollisionEnter(collision: Collision) {
    const count = collision.getContacts(this._contacts);
    console.log("碰撞开始，对象：", collision.collider.entity.name, "接触点数：", count);
  }

  onCollisionStay(collision: Collision) {
    console.log("碰撞持续中，对象：", collision.collider.entity.name);
  }

  onCollisionExit(collision: Collision) {
    console.log("碰撞结束，对象：", collision.collider.entity.name);
  }

  // 触发器事件
  onTriggerEnter(other: Collider, self: Collider) {
    console.log("触发器开始，对象：", other.entity.name);
  }

  onTriggerStay(other: Collider, self: Collider) {
    console.log("触发器持续中，对象：", other.entity.name);
  }

  onTriggerExit(other: Collider, self: Collider) {
    console.log("触发器结束，对象：", other.entity.name);
  }
}
```
