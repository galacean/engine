碰撞器（[Collider](/apis/core/#Collider)）是为实体提供碰撞形状的组件。每种形状都是一个独立的组件：

| 组件 | 形状 | 说明 |
| :-- | :-- | :-- |
| [**BoxCollider**](/apis/core/#BoxCollider) | 盒 |  |
| [**SphereCollider**](/apis/core/#SphereCollider) | 球 |  |
| [**CapsuleCollider**](/apis/core/#CapsuleCollider) | 胶囊 |  |
| [**PlaneCollider**](/apis/core/#PlaneCollider) | 朝向实体局部 +Y 轴的无限平面 | 只能是静态或运动学 |
| [**MeshCollider**](/apis/core/#MeshCollider) | 由网格生成的凸包或三角网格 | 三角网格（`convex = false`）只能是静态或运动学 |
| [**CharacterController**](/apis/core/#CharacterController) | 自带移动算法的胶囊 | 见[角色控制器](/docs/physics/collider/characterController) |

## 静态还是受物理驱动

碰撞器是否随物理运动由层级决定，而不是由碰撞器本身决定：

- **静态**：所在实体及其祖先上都没有[刚体](/docs/physics/collider/rigidbody)的碰撞器是静态的。它跟随自身实体，修改实体的变换会把它直接移动（瞬移）到新位置。
- **归属刚体**：碰撞器所在实体或其祖先中最近的刚体拥有该碰撞器，碰撞器随该刚体运动。`collider.attachedRigidbody` 返回这个刚体，静态碰撞器返回 `null`。

要组合出复合形状，可以在同一实体上添加多个碰撞器组件，或把它们放在同一个刚体下的子实体上。嵌套的刚体会单独成组：它下面的碰撞器属于它，而不属于外层刚体。

[PlaneCollider](/apis/core/#PlaneCollider) 和 `convex = false` 的 [MeshCollider](/apis/core/#MeshCollider) 只能是静态的，或属于运动学刚体。放在非运动学刚体下时，它们会退出模拟和查询并输出控制台错误，直到刚体变为运动学。

### 禁用与移除

| 操作                 | 结果                                                                                        |
| :------------------- | :------------------------------------------------------------------------------------------ |
| 禁用碰撞器           | 该碰撞器退出模拟和查询，重新启用后恢复                                                      |
| 禁用所属刚体         | 刚体及其拥有的所有碰撞器退出模拟和查询；它们**不会**变成静态碰撞器，各自的 `enabled` 值不变 |
| 移除（销毁）所属刚体 | 它拥有的碰撞器变为静态，或归属层级更上方的下一个刚体                                        |

组件的改动会在每次物理模拟步进前统一应用；在 [PhysicsScene.autoSyncTransforms](/apis/core/#PhysicsScene-autoSyncTransforms) 为 `true`（默认）时，也会在每次查询（射线检测、形状投射、重叠检测、`getClosestPoint`）之前统一应用，因此添加或启用组件的先后顺序不影响结果。当 `autoSyncTransforms` 为 `false` 时，如需在下次模拟步进前让查询立即生效，可调用 [PhysicsScene.syncTransforms](/apis/core/#PhysicsScene-syncTransforms)。

## 通用属性

所有碰撞器组件都具有以下属性：

| 属性 | 描述 | 默认值 |
| :-- | :-- | :-- |
| [**center**](/apis/core/#Collider-center) | 形状在实体局部空间中的中心，会乘以实体的带符号世界缩放 | (0, 0, 0) |
| [**isTrigger**](/apis/core/#Collider-isTrigger) | 是否为触发器。触发器只报告重叠，不产生碰撞响应。见[碰撞事件](/docs/physics/collider/event) | false |
| [**material**](/apis/core/#Collider-material) | 指定的[物理材质](#物理材质)，为 `null` 时使用共享默认材质 | null |
| [**collisionLayer**](/apis/core/#Collider-collisionLayer) | 碰撞器所属的碰撞层，只能是单个层。见[碰撞层](/docs/physics/collider/collisionLayer) | Layer.Layer0 |
| [**contactOffset**](/apis/core/#Collider-contactOffset) | 接触偏移。非有限值会抛出异常，负值会被限制为 0 | 0.02 |
| [**attachedRigidbody**](/apis/core/#Collider-attachedRigidbody) | 只读。拥有该碰撞器的刚体，没有时为 `null` | - |

形状尺寸跟随实体世界缩放的绝对值，`center` 则乘以带符号世界缩放（负缩放会镜像偏移）。实体在非等比缩放的祖先下旋转可能产生切变，物理会忽略切变。开启日志时，碰撞器会提示一次。

| 方法 | 描述 |
| :-- | :-- |
| [**getClosestPoint**](/apis/core/#Collider-getClosestPoint) | 返回世界空间中某点到碰撞器的距离并写出最近点。碰撞器不在模拟中时返回 -1。PlaneCollider、CharacterController 与非凸 MeshCollider 不支持 |

## 形状属性

### BoxCollider

| 属性                                     | 描述                     | 默认值    |
| :--------------------------------------- | :----------------------- | :-------- |
| [**size**](/apis/core/#BoxCollider-size) | 盒在实体局部空间中的尺寸 | (1, 1, 1) |

### SphereCollider

| 属性                                            | 描述                     | 默认值 |
| :---------------------------------------------- | :----------------------- | :----- |
| [**radius**](/apis/core/#SphereCollider-radius) | 球在实体局部空间中的半径 | 1      |

### CapsuleCollider

| 属性                                                   | 描述                         | 默认值                |
| :----------------------------------------------------- | :--------------------------- | :-------------------- |
| [**radius**](/apis/core/#CapsuleCollider-radius)       | 胶囊在实体局部空间中的半径   | 1                     |
| [**height**](/apis/core/#CapsuleCollider-height)       | 总高度，包含两端半球 | 4                     |
| [**direction**](/apis/core/#CapsuleCollider-direction) | 胶囊对齐的局部轴             | CapsuleColliderDirection.Y |

### PlaneCollider

PlaneCollider 没有形状属性。它是朝向实体局部 +Y 轴的无限平面，可通过实体旋转调整朝向。它只能是静态的或归属于运动学刚体，且不支持 `getClosestPoint()`（返回 `-1`）和体积距离查询。

### MeshCollider

| 属性 | 描述 | 默认值 |
| :-- | :-- | :-- |
| [**mesh**](/apis/core/#MeshCollider-mesh) | 用于碰撞的 [ModelMesh](/apis/core/#ModelMesh)。网格数据在上传后必须保持可访问，三角网格还需要索引；无效网格在同步时会移出模拟与查询，替换为有效网格后自动恢复 | null |
| [**convex**](/apis/core/#MeshCollider-convex) | 是否使用由网格顶点生成的凸包。非凸网格不可作为触发器，也不可挂在非运动学刚体下；非法组合会在同步时移出模拟与查询，修正后自动恢复 | false |
| [**cookingFlags**](/apis/core/#MeshCollider-cookingFlags) | 网格烘焙标志（`MeshColliderCookingFlag`） | Cleaning \| VertexWelding |

## 物理材质

- [**material**](/apis/core/#Collider-material)：读取或指定一个 [PhysicsMaterial](/apis/core/#PhysicsMaterial)，不会创建或克隆材质。修改材质会影响所有引用它的碰撞器。`null` 表示使用共享默认材质。指定属于其他引擎的材质会抛出异常。

克隆实体后，克隆出的碰撞器与原碰撞器共享同一个材质引用；如需独立材质，可显式赋值 `collider.material.clone()` 或 `new PhysicsMaterial(engine)`。自己创建的材质在不再被碰撞器使用后应调用 `destroy()` 释放，共享默认材质无需手动清理。

| 属性 | 描述 | 默认值 |
| :-- | :-- | :-- |
| [**staticFriction**](/apis/core/#PhysicsMaterial-staticFriction) | 物体静止时的摩擦系数 | 0.6 |
| [**dynamicFriction**](/apis/core/#PhysicsMaterial-dynamicFriction) | 物体运动时的摩擦系数 | 0.6 |
| [**bounciness**](/apis/core/#PhysicsMaterial-bounciness) | 弹性系数，范围 0（不反弹）到 1 | 0 |
| [**bounceCombine**](/apis/core/#PhysicsMaterial-bounceCombine) | 两个物体弹性系数的组合方式：Average、Minimum、Maximum 或 Multiply | Average |
| [**frictionCombine**](/apis/core/#PhysicsMaterial-frictionCombine) | 两个物体摩擦系数的组合方式：Average、Minimum、Maximum 或 Multiply | Average |

## 脚本使用

### 静态碰撞器

```typescript
import { BoxCollider, PlaneCollider, Vector3 } from "@galacean/engine";

// 墙体及其祖先没有刚体，因此墙体是静态的。
const wall = rootEntity.createChild("wall");
const wallCollider = wall.addComponent(BoxCollider);
wallCollider.size = new Vector3(5, 3, 0.5);

const ground = rootEntity.createChild("ground");
ground.addComponent(PlaneCollider);
```

### 受物理驱动的碰撞器

```typescript
import { BoxCollider, Rigidbody, SphereCollider, Vector3 } from "@galacean/engine";

const box = rootEntity.createChild("box");
box.transform.setPosition(0, 5, 0);
box.addComponent(Rigidbody);
box.addComponent(BoxCollider);

// 机器人刚体同时拥有躯干和头部的碰撞器。
const robot = rootEntity.createChild("robot");
robot.addComponent(Rigidbody);
const body = robot.addComponent(BoxCollider);
body.size = new Vector3(1, 2, 1);
const head = robot.createChild("head");
head.transform.setPosition(0, 1.5, 0);
head.addComponent(SphereCollider).radius = 0.5;
```

### 触发器

```typescript
import { BoxCollider, Collider, Script, Vector3 } from "@galacean/engine";

const zone = rootEntity.createChild("zone");
const zoneCollider = zone.addComponent(BoxCollider);
zoneCollider.size = new Vector3(4, 2, 4);
zoneCollider.isTrigger = true;

class ZoneScript extends Script {
  onTriggerEnter(other: Collider, self: Collider) {
    console.log(`${other.entity.name} 进入了 ${self.entity.name}`);
  }
}
zone.addComponent(ZoneScript);
```

### 物理材质

```typescript
import { BoxCollider, PhysicsMaterial, SphereCollider } from "@galacean/engine";

const sharedMaterial = new PhysicsMaterial(engine);
sharedMaterial.dynamicFriction = 0.4;

const box = entity.addComponent(BoxCollider);
const sphere = entity.addComponent(SphereCollider);
box.material = sharedMaterial;
sphere.material = sharedMaterial;

// 盒子使用独立材质，球体继续使用共享材质。
const customMaterial = sharedMaterial.clone();
customMaterial.bounciness = 0.8;
box.material = customMaterial;
```

## 最佳实践

- 优先使用能满足需求的最简单形状：盒、球、胶囊的开销都低于网格碰撞器。
- 运动的物体使用凸包 MeshCollider；三角网格（`convex = false`）只用于静态或运动学几何体。
- 永远不会移动的物体不要添加刚体，让它保持静态。
- 只需要检测重叠时，使用触发器代替物理碰撞。

## 从碰撞形状迁移

早期版本把形状对象添加到 `StaticCollider` 或 `DynamicCollider` 组件上。现在形状本身就是碰撞器组件，运动由独立的刚体组件负责，且没有兼容层。

| 旧写法 | 新写法 |
| :-- | :-- |
| `DynamicCollider` | [`Rigidbody`](/docs/physics/collider/rigidbody)，管理刚体属性和运动 |
| `DynamicColliderConstraints` | `RigidbodyConstraints` |
| `StaticCollider` | 已移除：实体及其祖先上没有刚体的碰撞器就是静态的 |
| `new BoxColliderShape()` + `collider.addShape(shape)` | `entity.addComponent(BoxCollider)`；`SphereCollider`、`CapsuleCollider`、`PlaneCollider`、`MeshCollider` 同理 |
| 一个碰撞器上添加多个形状 | 在同一实体上添加多个碰撞器组件，或放在刚体下的子实体上 |
| `removeShape()` / `clearShapes()` / `shapes` | 已移除：禁用或销毁碰撞器组件 |
| `shape.position` | `collider.center` |
| `shape.rotation` | 使用实体或子实体的 `Transform.rotation` |
| `meshShape.isConvex` | `meshCollider.convex` |
| `capsuleShape.upAxis` | `capsuleCollider.direction` |
| `ColliderShapeUpAxis` | `CapsuleColliderDirection` |
| `MeshColliderShapeCookingFlag` | `MeshColliderCookingFlag` |
| `shape.material` / `shape.getInstanceMaterial()` | `collider.material`（需要独立材质时显式赋值 `material.clone()` 或 `new PhysicsMaterial(engine)`） |
| `shape.isTrigger` | `collider.isTrigger` |
| `joint.connectedCollider` | `joint.connectedBody`（`Rigidbody` 或 `null`） |
| `onTriggerEnter(other: ColliderShape)`（Stay/Exit 同理） | `onTriggerEnter(other: Collider, self: Collider)` |
| `collision.shape` | `collision.collider`（另一个碰撞器）和 `collision.selfCollider` |
| `hitResult.shape` | `hitResult.collider` |
| 返回 `ColliderShape[]` 的 `overlap*All()` | 返回 `Collider[]` 的 `overlap*All()` |
| `characterController.addShape(capsule)` | `characterController.radius`、`height` 和 `center` |

迁移旧场景、Prefab 或脚本时，请把碰撞体和角色控制器的胶囊高度加上两倍半径，并将刚体角速度和最大角速度乘以 `Math.PI / 180` 换算为弧度/秒；同时注意 `PhysicsScene.capsuleCast` 与 `overlapCapsuleAll` 的默认局部长轴已统一为 Y 轴（与 `CapsuleCollider`、`CharacterController` 一致），且 `Collider.center` 现按带符号世界缩放镜像偏移。
