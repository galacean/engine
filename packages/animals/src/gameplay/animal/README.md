# 动物系统

> 当前 Seed 接入契约以 [正式动物资源说明](../../../demos/terrain/seed-world-planner/planning-data/animals/README.md) 为准。下文带日期的段落保留各阶段验证记录；旧 17 体型、圆形活动范围、串行加载及飞鸟落地后休眠策略已由 114 模型、全图分布、按需并行加载和统一模拟圈替代。历史本机 evidence 路径不是本次提交的发布资源。

系统遵循 [World Engine 各系统接入规范](https://yuque.antfin.com/galacean-engine/roadmap/mg05dhknixor7w1o) 的 Entity / Component / Asset / Scene 分层。动物内容、实例保存、行为执行与宿主空间查询分别承担自己的职责。

## 配置动物的资源与保存协议（2026-10-15）

`AnimalAssetCatalog` 保存作者配置，`AnimalRegistration` 保存语义和行为权重。`AnimalAssetLibrary` 解析稳定的 `{ typeId, appearanceId }`；`typeId` 对应目录条目的 `id`，`appearanceId` 对应其外观条目的 `id`。目录默认外观会解析成明确的 `appearanceId`，保存后不会因为未来修改默认值而偷偷更换外观。无外观列表的资源使用 `appearanceId: "default"`。

自主移动和明确移动指令都由目标位置决定完成，不接受 `cycles` 动画段数上限。逐段 Once 步态结束仍按注册权重选择下一段，并保持同一个目标；到达、不可达、超时或新指令才结束这次移动。宿主控制可活动范围和目标距离，动画时长不决定行为意图。


实例使用 `AnimalInstanceDocument`，例如：

```json
{
  "version": 1,
  "id": "seed-123-animal-bears-adult-0",
  "typeId": "bears-adult",
  "appearanceId": "bears-adult--lowpoly-bear-01",
  "position": [12, 3.5, -7],
  "heading": 0.4,
  "scale": 1
}
```

位置单位是米，heading 是绕世界 +Y 的连续弧度，scale 是实例绝对标定缩放。读档保留 id；新建/复制实例另分配 id。`readAnimalInstanceDocument` 验证并复制上述字段，不保存 URL、网格、纹理、动画曲线或行为树临时执行栈。宿主恢复后下发 idle 指令继续自主行为。协议验证不等于已经接入标准 SceneLoader。

加载走引擎原生 `ResourceManager.load({type: AssetType.GLTF, url})`：规范化成相同绝对 URL 的并发和后续请求共用原生缓存。`GLTFResource.instantiateSceneRoot()` 原生克隆 Entity/骨架，每个 `ConfiguredAnimal` 独立执行动画，但借用共享 mesh/material/animation clip。实例 dispose 只销毁自己的实体、控制器和材质修正，不销毁共享 GLB。缓存存活遵循原生 ResourceManager 的销毁/GC 规则。`AnimalAssetLibrary` 不另建下载缓存或引用计数。

原生 `PrefabResource.instantiate()` 同样克隆实体模板，可用于作者把组件与资源引用组装成 Prefab；它不是每只动物各存一份二进制的存档协议。当前配置动物直接消费 GLTFResource，没有为每个外观生成重复 Prefab，也没有宣称已实现配置动物的标准 Scene/Prefab 序列化适配。

当前 LowPoly Wild 内容：189 个外观共享两张外部调色板纹理；相同外观的多只动物共用 GLB 资源。**不同外观仍是不同 GLB，内部动画曲线仍重复**，不能把同外观复用描述为跨外观复用。进一步拆分需离线输出每组一份动画库、每外观一份网格/UV，并校验层级、bind pose 和轨道路径后由原生 Animator 绑定共享 clip；不应在运行时盲目按动画名替换骨架。该拆分尚未实施。

资源复用与协议回归见 `tests/AnimalAssetLibrary.spec.ts`：原生 ResourceManager 加载合并、34 个并发实例、失败重试、不同外观隔离、189 个引用解析、稳定实例 ID 与 JSON 往返。ConfiguredAnimal、目录与注册编译器已从 demo 提升到本目录，旧 demo 路径仅保留兼容导出。

## 配置动物的步态位移硬边界（2026-10-15）

`ConfiguredAnimal` 在 crowd 提交位置之前采样真实 Animator。移动许可必须同时满足：行为树选中可移动步态、原生状态回执确认这次采样仍在播放且未结束、校正源 root motion 后的模型局部姿态实际变化。逻辑 `AnimalMotionPlayback.elapsed` 只负责请求区间，不能独自证明动画在播放。idle、暂停、片段结束、同一播放帧、静止姿态均返回零位移比例，同时锁住平移和转向；保留的目标与残余速度不得绕过。

原生 crossfade 会忽略目标等于当前 source/destination 的请求；每片段预建3个共享clip的状态绑定，使 `walk → idle → walk` 和重复播放都能避开占用绑定，从当前显示姿态继续混合。目标绑定的原生回执配合实际姿态采样控制根运动许可，物理起步加速独立于混合权重。状态回执只记账，行为完成/唤醒仍在运动阶段后执行。每个实例复用局部 TRS 数组，不新增计时器或每帧数组分配。

真实 GLB 回归入口为 `shared/gameplay/tests/runtime/configured.html`。熊、鹿、狼共 93 项检查包含脚/蹄关节链姿态与根位移/转角的独立采样，不再只核对本地计时器。该历史验证所用旧包及证据目录已移除，当前回归入口默认使用 Seed 配置。没有将三个骨架样本宣称为全部动画语义验收或 100 只完整 Seed 性能证明。

## Seed 按需加载与语义工具（2026-10-15）

Seed 只静态创建轻量 `PlanningAnimalHost`。关闭时不导入运行库/大目录、不构造栖息地/群体/实体，也不安装动物帧回调。世界 publication 仅记录参数；主场景就绪后才动态导入 runtime、预先固定米制圆形活动范围并建立障碍空间索引，创建确定性的身份及静态碰撞占位。默认每个体型 min=max=1，共17个体型。

动物范围统一以米配置：`spawnRadius` 默认120米、`roamRadius` 默认160米，都以世界最初出生点为固定圆心，出生半径不得大于活动半径。`activationDistance` 默认160米，以当前观察相机（通常为玩家视角）为中心，只用 X/Z 水平距离平方控制加载、显示和模拟。三个参数均为正有限米数，不再按 POI 层数或归属限制动物。可经参数事务/LLM/同一 dat.gui 修改；数量仍用只数。当前群体按距离最近优先，一次等待一个模型，不预加载远处模型；修改激活距离不会重排出生。主世界的光照、植被、保存不等待动物 GLB。旧存档的 POI 范围没有固定米数换算，载入时清除旧键并继承米制默认值；已保存的启用、数量、激活距离和新米制半径保留。

远处保留原位置及 crowd 空间索引的静态足迹，停止动画采样、行为决策、运动和该动物的 deadline。`AnimalSystem.schedule(delay, callback, owner)` 可选 owner 让倒计时暂停并保留剩余时长；ConfiguredAnimal 使用该语义。传统不传 owner 的调用仍使用 Scene 时间。所有动物都隐藏时跳过整个模拟时钟。位置不变则跳过重复距离判断；移动后只做水平距离平方比较。运动前检查动物完整足迹是否仍在固定活动圆内，再检查真实支撑、水和预建障碍索引，不查询或更新 POI 归属，也不因玩家移动扩展活动范围。跨越内部 POI 分界没有特殊逻辑；活动范围边缘的无效移动由碰撞/转向处理，不传送动物。

关闭或重建会撤销旧消费者等待，不再发新请求，晚到结果不创建实例。`AnimalAssetLibrary.load` 的 AbortSignal 只取消自己的等待；已发送的同 URL 原生共享请求可继续完成进入缓存，不对其他模块调用全局 cancel/GC。快速重开时旧共享请求可能仍在途，因此一次一个指当前群体等待队列，不保证整个引擎永远只有一个在途请求。已加载资源保留原生缓存以便复用；这不是内存完全释放保证。

Agent 通过 `world.animals.query / describe / command / receipt` 发现真实身份、语义技能、目标和回执，UI使用同一个服务。查询不触发资源加载。未知/未加载/隐藏动物拒绝新命令；同 requestId 同内容仅返回原回执，新 requestId 立即替换且无冷却。当前位置目标仅接受有限 x/z，必须满足活动区域和直达支撑/障碍检查。当前 Seed 已将 alphamap 草地区域注册为简化的草食物目标，提供 eat 语义指令；水边/喝水仍未接入，不把“去河边喝水”伪装成已完成动作。动画片段/权重由注册与行为树持有，不暴露给LLM。

## 固定 Seed 的动物群复现

每类请求数量由世界 seed、稳定 typeId 和独立 count 随机流在 min/max 闭区间中确定；不会在刷新时使用时间或 Math.random 重新抽数。min=max 固定数量，0/0 禁用该类，0/N 允许该 Seed 抽到0只。相同 seed、有效参数、素材配置版本及发布世界几何/通行条件会重建相同类型、数量、初始位置和朝向；出生碰撞候选也按固定顺序检查，失败以诊断报告，不按加载结果补抽。保存作者 seed/参数即可，不需要缓存一份随机生成数量。

加载顺序、当前相机和激活距离只影响已加载/可见数量，不改变出生名单。刷新后重新开始自主行为，不保证经过不同帧时间、加载时序与交互后的位置或动画帧相同。既有存档显式 min/max 优先于新的默认1/1。dat.gui「运行快照 → 采集当前快照」中的 seed/config/births/requestedCount 可核对初始名单；不能只比较画面上的可见只数。

## 按个体选择初始化变体

群体配置的每个 `types[]` 可提供 `appearances: [{ appearanceId, weight }]`。先调用 `AnimalAssetLibrary.resolvePopulationConfig(config)`，再把返回配置交给纯函数 `planAnimalPopulation`：资源库验证ID并把未配置的候选补全为该体型全部外观、权重均为1，不下载模型。纯规划函数没有素材目录，不能自行发现未提供的候选。旧 `appearanceId` 继续表示固定外观，不能与候选列表同时提供；单资源 `library.resolve({ typeId })` 仍选择目录代表外观，与群体默认等权重抽样分别对应不同用途。

例如以下配置让同一体型每只动物从两个变体中独立选择，第二个概率为2/3，允许重复：

```json
{
  "typeId": "boars-cub",
  "min": 1,
  "max": 2,
  "appearances": [
    { "appearanceId": "boars-cub--lowpoly-boar-cub-1", "weight": 1 },
    { "appearanceId": "boars-cub--lowpoly-boar-cub-6", "weight": 2 }
  ]
}
```

权重是相对概率，不是配额或优先必选规则。候选先按稳定ID排序，再用世界seed、typeId和个体序号组成的独立appearance随机流抽样。调整候选列表顺序不改变结果；增加数量不改变已有序号的外观；抽样在落点检查和异步加载之前完成，落点重试不重抽外观。出生记录、加载引用与实例保存消费同一明确appearanceId。改变外观可能改变真实碰撞尺寸，因而也可能影响落点接受结果。

Seed 的初始化入口是 `demos/terrain/seed-world-planner/planning-data/animal-appearances.json`，默认文件为 `{}`，自动从目录发现17个体型的189个变体并使用权重1，无需重复配置。该配置仅由按需运行库消费，不新增dat.gui或LLM初始化参数；每帧不执行变体抽样。

## 早期组件能力与兼容接口

下文记录原有 `AnimalComponent` 的鸟/同伴绑定方式。配置素材使用上面的共享目录与 `ConfiguredAnimal`，两者消费同一 `AnimalSystem` 调度机制；旧坐骑 API 的保留不代表 Seed 必须继续创建马。

## 所有权与职责

| 对象 | 职责与所有权 |
| --- | --- |
| `AnimalSpeciesDocument` / `JSONAsset` | 可保存的物种数据：模型引用、运动能力、行为树、动画别名、可选坐骑标定和三档 LOD。可以通过标准 JSON loader 加载。 |
| `AnimalComponent` | 标准 Scene Script，保存共享 `species` / `model` 引用和实例 `settings`，创建实例，绑定能力，处理启用、停用和销毁。 |
| `AnimalSystemComponent` / `AnimalSystem` | 每 Scene 一个时钟。统一可取消 deadline 堆、去重决策队列和运动活动集合。不同能力共用每帧决策预算。 |
| `Animal` | 无引擎依赖的基础闲逛、起飞、飞行和落地任务。当前支持平面圆形活动范围。 |
| `AnimalCompanion` | 地面同伴能力：命令收据、召唤、接近、跟随、寻找草地、骑乘、下马和退场。宿主通过 `AnimalHost` 提供地面和玩家服务。 |
| `GLBAnimalPresenter` / `AnimalModelLod` | 绑定实例动画、染色和几何 LOD。行为状态不依赖骨骼名、材质名、模型 URL 或 LOD。 |

实例拥有自己的行为执行、控制器、动画事件/绑定元数据和染色材质；GLTF 网格、纹理和动画曲线由资源 owner 共享。系统不向共享动画追加完成事件。能力取消、组件销毁和异步加载失败必须撤销注册、计时器、订阅以及实例资源。

`settings` 是创建/重建时使用的实例配置。直接修改其中的缩放或模式不会热重建正在运行的实例；运行中的同伴行为通过 `execute()` 修改。尚未接入编辑器表单，也未实现运行中行为树执行栈的存档恢复。

## 创建与 Scene 接入

运行时使用 `AnimalComponent.create(parent, speciesDocument, settings)`。自由闲逛选择 `mode: "roaming"`，地面同伴选择 `mode: "companion"` 并提供 `host`。模式对应能力，不以物种名称分支。同一个 Scene 内的这两类动物会自动共享时钟。

Scene/Prefab 接入先调用 `registerAnimalComponents()`。用标准资源引用设置 `species: JSONAsset`、`model: GLTFResource` 和可序列化 `settings`，`onStart` 调用与运行时创建相同的初始化方法。同伴的 `host` 是运行时服务，由宿主在初始化前绑定，不写入物种资产或实例 settings。

独立闲逛 demo 仍保留原调用方式，也可以直接使用纯 `AnimalSystem.createAnimal()`；本次不改 demo 应用代码。旧 `HorseModule.create(parent, host, behavior?, scale?)` 返回实际的 `AnimalComponent`，Seed 原入口与骑乘 Host 保持兼容。`horse/` 只保留物种预设、模型标定、内容资源和旧名称兼容导出。

## 时钟、暂停与生命周期

命令、动作完成和动画事件只入唤醒队列；不在回调中递归执行行为树。默认每帧最多 32 次决策。静止闲逛动物离开运动集合；同伴感知使用同一模拟时钟的 0.5 秒 deadline，不使用 `setTimeout` 或每动物定时器。原马的任务超时也迁入同一堆。

关闭动物组件会移除活动运动与待决策，暂停同伴 Animator 和感知。Scene 时间继续推进，任务 deadline 保留 Scene 时间语义；重新启用时根据最新状态恢复执行，关闭组件不代表全局时间暂停。全局 `system.update(0)` 同时冻结模拟时间和决策。

系统组件随 Scene 销毁；单个动物销毁只注销自己，不销毁共享模型或其他动物。模拟状态不受几何 LOD 切换影响。

## 三档 LOD

只有 LOD0、LOD1、LOD2，低于末档阈值停止提交 renderer，不增加第四个几何档位。资产可在单个 GLB 中包含三个互不重叠的模型子树，通过 `lod.roots` 精确绑定；所有模型 renderer 必须恰好归属一档。骨骼/动画绑定可以共享。

`lod.size` 是 GLB 根空间的固定参考直径，运行时乘真实模型世界缩放。透视相机使用 `size / (2 * distance * tan(fovY / 2))` 得到屏幕高度占比；正交相机使用 `size / (2 * orthographicSize)`。使用固定最大姿态参考，振翅不会改变阈值。切换有 15% 滞回，LOD2 关闭投影阴影。设置组件 `lodCamera` 后自动观察相机；不提供相机时保持初始 LOD0。

建议鸟的离线预算：LOD0 为现有 9,956 三角形，LOD1 约 3,000，LOD2 约 500。当前 `songbird.glb` 只有一个几何等级，本次不生成或宣称已有低模。三档绑定已实现，动画求值降频、GPU 蒙皮实例化和跨档淡入淡出尚未实现。

Seed 当前的树与多种素材采用屏幕占比阈值，调试面板的距离倍率乘在投影结果上；同时保留终端距离裁剪、草地距离淡出和分区驻留。因此不能把整个 Seed 的所有 LOD 统称为纯屏幕占比，或纯固定距离。

地面程序转向由共享 `GroundAnimalSteering` 统一处理：体长/标称步速确定基础角速度，上一子步实际移动速度进一步约束转向；绝对上限0.3 rad/s，角加速度不超过0.3 rad/s²。较慢的小步转身仍须通过真实步态推进许可，静止/结束动画不能旋转。近目标的减速使用同一动态转向上限，避免因减慢转向反而围绕目标打转。Crowd在原有目标相对方向之外保留当前朝向与上一避让方向作为候选，继续共用邻居列表与扫掠碰撞约束，没有每动物定时器或新增每帧分配。


`ConfiguredAnimal`统一将手动选择、单次片段重播和快速行为打断转为原生crossfade，默认1模拟秒，并按实际播放速率换算原生混合时长。每片段预建3个共享AnimationClip的原生状态绑定，避开当前源/目标绑定，支持在未完成的混合中立即重播并从当前姿态接续；只在初始构造和明确seek时直接play。脚步采样回执跟踪实际目标绑定，源状态退出不会误判目标完成；帧更新不新建状态或复制骨骼/曲线，资源仍共享。motionSync中的原生片段名映射回内容ID，内部绑定名仅作为诊断目标状态供原生回归定位。

### 2026-10-16 慢速转向与指令位移

crossfade仅混合骨骼姿态，不再逐子步乘到物理速度上。原生姿态确实推进（浮点差阈值1e-7）、未暂停且未结束仍是根位移/转向许可；物理加速由共享转向器处理。转向角速度上限0.3rad/s，角加速度不超过0.3rad/s²，并按0.12+实际步速/(体长×1.25)收紧。局部候选方向与实际移动复用同一刹停限速函数，增加反向角动量成本，避免停步后反复改转向侧。动态堵停由求解器的可通行速度和扫掠约束报告，不把起步/片段边界的静止帧当作拥堵。堵停状态变化唤醒行为树切到等待 idle，保留目的地；前方可通行时恢复原目标，不要求等当前步态播完。原地旋转不能单独解除堵停；新明确指令可以立即打断等待。

### 素材骨架朝向与根节点诊断

根节点转速不能代表骨架在clip混合中的真实转动。100款包中发现Bison_Walk骨架根与Idle/Run反向约180度，导致混合时约468度/秒的可见快转。该问题通过资产导入期的显式clip朝向修正解决，运行时仍使用原生混合、同一GLB/曲线共享和单次片段调度，不按动物ID增加帧内分支。程序转弯上限进一步收紧为0.3rad/s，前向半速绕弯，候选方向加入4个朝向相对缓弯出口。独立原生fixture同时记录根节点转角和前后脚骨连线朝向，防止再次用根节点限速漏掉素材内部翻身。

### 2026-10-20 急转弯半径与素材节拍

完整和粗模拟共用边界几何引导与落地校验，不预演未来路线；实际运动步长仍为完整 1/60 秒、粗运动 0.1 秒。同目标的动画续播不清除尚未处理的路线失效标记；跨模拟精度切换保留线速度与角速度，真正暂停才清零。粗模拟不求解动态避让或预测空中交通，仅在接近目标和实际落地时查询局部占位。

空中持续运动优先于避碰：共享 crowd 不对含 air 的配对施加硬停，Seed 的 air 通行仅校验地图范围与有效中心高度，不因建筑、植被或外围水陆接触阻断飞行。允许空中交叉和穿过静态实体；地面/水面仍保留避让、扫掠约束与落地占位校验。原有额外预测边距及邻居飞行缓存已删除。原生 `simultaneous-flight` 验证迎面同时起飞不中断并各自合法落地。此策略不是三维绕障寻路。

Seed 宿主向全部已加载且有效的完整/粗模拟实例派发天气事件和语义指令。明确坐标校验前先补齐当前运动；查询不创建模型，未加载或真正暂停的实例不接收执行。近远共用行为树语义，不代表动态避让或骨骼采样也必须相同。宿主仍有轻量距离/位置检查；到期回调可能同批集中，不能将按需决策描述为整个宿主零每帧开销。

落点在飞行中失效时，临时续飞目标仅用于转向器，语义 destination 和原任务保持不变；复用现有探测时钟继续前飞并保持空中高度，接受新合法落点后退出续飞。手动播放/重置清理旧目标，暂停/精度切换保留当前意图。`occupied-landing` 原生回归覆盖原落点持续被占 3 秒、无停帧前进、最终安全落地。相同同步目标求解内重复失败端点只校验一次；目标查询及随机消费不变，下一次求解重新检查。

### 飞行边界与落点（2026-10-26）

`AnimalGroundSurface.flightBounds` 提供宿主矩形/圆形地图边界。Seed 直接传入已发布的全图范围；位置积分仅做常数时间边界包含判断，不采样空中整条路线的地形、水陆或障碍。每步按速度和转向上限算安全转弯余量，再由原运动器限制角速度与角加速度。贴近边界、已经对齐的合法降落允许继续减速落地。

新目标只查询一次落点支撑与占位，并用角度/距离和下降速度判断过近的反向目标。巡航时不轮询落点；进入最后约 3 秒航程才每 0.25 秒复核，实际接触再检查当前位置的水陆/占位。降落提前降低高度，避免水平先停而仍悬空。目标失效时 `continuous` 转向意图保留最低前进速度，按共享时钟申请替代落点；不会将临时转向点当作到达地点。该标记不修改素材/注册的转向速度。

完整与粗模拟使用同一规则。粗模拟巡航只采样一次当前高度，最后下降阶段才按运动子步更新高度。原地等待仍由共享截止事件驱动；渲染状态不创建另一套行为时钟。Seed 对恢复后的宿主帧时间上限为 0.1 秒，不补算后台积累的整段墙钟时间。真正暂停保持冻结的任务和相位，恢复后重新加速；近远精度切换保持速度、朝向、位置和相位。

原生测试页 `configured.html` 覆盖跨岛飞行、实际落点被占、边界持续无可用落点、贴边合法降落、天鹅水面降落和反复精度/暂停切换。`case=flight-lifecycle&background=1` 额外等待真实 hidden/visible 事件，未收到事件不能视为后台恢复通过。`profile=1&profileHost=1` 只在测试页按需启用，分解调度、动作、运动、落点、高度与通行成本，不进入生产加载链路。

前一版保留预测时的 1.491 ms 及更早的 0.637 ms 是历史数据；最新测量与验证限制见工作树外 `animal-simple-flight-20261026/report.md`。不同轮次机器负载波动明显，不把粗模拟单批耗时当作整场景帧耗时或 GPU 开销。

### 夏夜萤火虫（2026-11-03）

`FireflyPopulation` 是 `AnimalSystem` 中的一个有界批量 agent，由 `PlanningAnimalRuntime` 创建、更新及释放。它使用现有动物运动时钟，不创建逐虫 Script、GLB、Animator 或点光源；固定天文时间时仍持续飞行。环境只提供 `summerWeight × nightFactor`，夏季夜间渐入，白天及其他季节渐出。详见[正式接入参数](../../../demos/terrain/seed-world-planner/planning-data/animals/README.md#夏夜萤火虫)。

默认相机附近最多 96 只、显示半径 48 米、速度 0.65 米/秒。世界按 24 米格子建立稳定 seed 身份，每格最多 8 个候选；驻留个体保留世界坐标，远处格子卸载后再进入会重建，飞行轨迹不保存。高度取地形和水面较高者上方，复用宿主 `canTraverseAir` 的现行边界语义；当前宿主检查地图边界、地形及已编译的静态实体体积；渲染深度另行处理遮挡，不宣称会主动规划绕障路线。

`FireflyPresenter` 用原生 BufferMesh/Material/Shader 绘制两批实例：朝向相机的解析圆形软边光核和柔光，位置共用一个动态缓冲。柔光在中心及其附近五点采样相机深度，淡化被遮挡的亮斑；不写深度、不投射阴影。发光只乘场景雾透射率，不重复叠加雾颜色。相机深度预通道通过已有租约共享，隐藏及销毁仅释放自身持有者。无独立周期闪烁、景深、历史可见性缓存或逐虫交互；这是本次效果与 Tiny Glade 的取舍边界。
