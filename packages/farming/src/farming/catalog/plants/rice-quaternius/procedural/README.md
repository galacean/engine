# 程序化水稻

沿用公共 PlantGeometryEvaluator / createProceduralPlant，无水稻专属运行时分支。

- `plant.json`：阶段文案、来源、材质、穗簇名称与计数单位。
- `recipe.json`：v3 模板文档。20 片叶引用一个 3×5 叶型模板，各自配置挂点、尺寸倍率和出生时间；无需逐片存储多阶段顶点。
- `atlas.png`：16 × 8 的两色材质色板。原模型没有图片纹理，叶缘和弯曲均由几何生成；颜色来自原 GLB 的 Green / LightGreen 线性 RGB，转换为 sRGB 存储。
- `generate.py`：Python 标准库即可重建配方和色板：`python3 generate.py`。

## 来源与边界

依据上级 `normalization-report.json` 四阶段株高（0.368、0.565、0.769、0.953 米）和原材质颜色人工编写结构规则。分蘖、叶片和穗粒布局为程序化重建，不是原 GLB 顶点逐个转换，也不是农学仿真。中间形态由公共曲线插值器生成；0% 是已有幼苗。当前成熟约 0.966 米，5 根分蘖、20 片叶、30 组穗簇，885 个顶点、1,330 个三角形。

移动端版将原 60 个籽粒合并为 30 组细长穗簇，并入穗轴连接，不再生成 60 根半径不足一毫米的独立小枝；保留七节点穗轴的下垂轮廓。主茎截面 5 边降为 4 边，穗轴 4 边降为 3 边，叶面从 3×9 降为 3×5。每组穗簇是视觉近似，界面数量不是实际谷粒数量或玩法产量。相较原 3,090 面，面数减少约 57%；近看穗粒排列会更疏，叶片弯曲也较简洁。

原始五个 GLB 已逐字节核对并归档至仓库外 `/Users/xingyi/Documents/data/glb/rice-quaternius/procedural-source/`，运行时不依赖该目录。四个生长阶段改为 proceduralAge。原 `crop` 是独立采收产物，不属于植株成长，因此移出当前预览清单，未伪装成成熟植株；原清单及产物模型保留于归档。
