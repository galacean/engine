# PR #103 提示查询与收回动画优化

## 范围

2026-10-28，基于 `66a464291`，落实本轮 CR-001、CR-002 两项 P2 建议。不改变 75% 移动打断规则、操作提交校验、道具朝向或动画时长。

## CR-001：复用提示查询

`FarmingWorldPresentation` 为提示动作保留一个缓存项，按农场快照、目标网格、地形视图及版本失效；有效与不可用结果都复用。缓存只供显示，点击和提交继续走原协调器、领域与地形校验。

遮挡结果按相机位置、目标点、地形视图及版本复用，更换宿主查询也立即失效。宿主动态障碍没有统一的版本通知，因此额外限制缓存寿命为 100ms；其变化最迟在到期后的下一次显示更新检查。提示屏幕投影和进度弧仍逐帧更新，原提交前遮挡校验不使用此缓存。

## CR-002：复用动画姿态

`FarmItemRetraction` 在创建时分配来源与目标姿态，每帧通过 `copyFrom` 更新目标。保留先捕获完整目标层级、再插值的顺序，首次 `apply` 前 `restore` 不改动姿态；已销毁节点跳过，其他节点的对应关系不变。

## 原生目标标签与 CR-003（2026-10-28）

按用户要求，目标点、动作图标、文字和进度环统一改为 Galacean `UICanvas` / `Image` / `Text`，移除挂载到页面的 DOM/SVG 标签。图标路径仅在初始化时栅格化为 Sprite 图集；临时画布不挂载到 DOM，进度环通过单个 UI Shader 的 uniform 更新。保留六种动作提示、遮挡、75% 变绿及完成/取消重置。所有 UI Renderer 禁用射线命中，释放时移除 Canvas、相机投影回调、尺寸观察器和自有资源，不销毁引擎共享字体。

投影使用相机 viewport，并在相机开始渲染时校正，避免相机控制器更新顺序导致标签滞后。画布显示尺寸通过 ResizeObserver 缓存，支持 CSS 缩放、不同渲染分辨率与高分屏字体；静止时不重复写入 UI 位置或参考分辨率。每帧不再读取 getBoundingClientRect 或写入 DOM 样式。

CR-003：普通悬停达到 180ms 稳定阈值后才读取地形三角形、创建并上传轮廓网格；执行动作绕过等待。只保留最新待显示目标，旧网格不在新目标上提前显示。淡入从实际显示时开始，隐藏时间不计入 120ms 淡入；更换目标、地形版本、动作或重新显示时正确重置。
