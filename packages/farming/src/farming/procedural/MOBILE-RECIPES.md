# 移动端配方精简

> 历史记录：下文描述当时实现与当时测量，旧 API、旧源格式和模型路线已移除。当前契约见 [公共 API](../README.md)，当前格式见 [程序化植物](README.md)，本轮结果见 [验收记录](../ROUND-1-ACCEPTANCE.md)。本轮未执行或追加性能测试。

配方继续采用 JSON。v2 用于实测叶面，v3 用于参数模板；两者统一为同一个只读求值结构，玩法规则、存档和生长进度映射不变。无需为各植物增加运行时条件分支。

| --- | --- | --- |
| 顶点 | 866 → 374（−56.8%） | 2,025 → 885（−56.3%） |
| 三角形 | 1,436 → 572（−60.2%） | 3,090 → 1,330（−57.0%） |

文件统计包含作者来源信息和可读格式，gzip 是离线压缩体积，不代表实际网络传输。当前 Vite 目录仍统一发现和加载配方；本次没有改为流式或按需网络加载。每株动态数据为 position + normal，共 6 个 float32（24 字节）/顶点。静止、成熟或不可见植株的跳过逻辑沿用现有调度器。

## 内容取舍

- 番茄：每组复叶 9×13 改为 5×7，保留叶根、叶尖、中脊和 UV 边界。六组复叶、十颗果实、原图集、支架和三个实测参考株高保留。各组叶子继续记录实测曲面，避免强制共用形状改变弯曲。
- 水稻：保留五个分蘖、二十片叶与七节点下垂穗轴。叶片共用一个 3×5 参数模板，通过各自的尺寸倍率、挂点和出生时间产生差异。主茎截面 5→4 边，穗轴截面 4→3 边。
- 水稻穗部：六十根微小侧枝并入穗簇连接，六十个谷粒改为三十组细长穗簇。界面按“组穗簇”显示，不把视觉部件数当作谷粒数或收获产量。近距离的穗粒排列较原先稀疏；成熟高度 0.960→0.966 m，其他参考阶段高度保持一致。
- 曲线：去掉恒定曲线与平台区间中的冗余点，保留每个变化区间的端点。不用线性简化删掉 smoothstep 中的转折点。离线统一保留 7 位小数，维持细茎精度。

不要通过大量透明面片补偿减面，本次水稻仍是实体几何和两色材质色板。没有增加纹理、材质、绘制批次或透明混合。

## 模板与生命周期

v3 文档字段与示例见 [README](README.md#移动端叶型模板version-3)。模板在配方入库时校验并展开一次，输出深度冻结的 v2 数据。实例创建和求值器再次收到该配方时直接复用，不再反复做 Zod 解析和深拷贝。外部可变输入不缓存，修改后仍须重新校验。

仅配方共享。各实例的顶点、法线、工作数组、材质、Mesh 与 GPU Buffer 继续独立，防止一株生长影响另一株。模板展开有采样预算；模板缺失、ID 冲突、混用两种叶片写法和非法尺寸会在 GPU 分配前报错。

## 重建与验证

```sh
python3 world/gallery/shared/farming/catalog/plants/rice-quaternius/procedural/generate.py
blender -b --python-exit-code 1 --python world/gallery/shared/farming/catalog/plants/tomato-bumroker/procedural/import.py -- --source-dir /path/to/archived/models
python3 -B world/gallery/shared/farming/tests/unit/recipe_authoring_test.py
pnpm --dir world farming:validate
pnpm --dir world typecheck:farming
pnpm --dir world test:farming
pnpm --dir world build:farming:all
```

源模型只用于离线重建，运行时不依赖个人路径。两份 atlas 与优化前逐字节一致。适配器重建会覆盖 recipe.json；调整作物默认数据时同步修改其适配器。

`tests/unit/mobile-recipes.spec.ts` 约束实际顶点/面数、文件体积、模板编译、非法输入与实例独立性；既有生长测试覆盖连续时间轴、反向拖动、正常法线和固定拓扑。`recipe_authoring_test.py` 验证冗余曲线清理前后的采样一致性及小尺寸精度。

浏览器验收包括番茄 0/55/100%、水稻 0/33/67/100%、窄视口、种植/浇水/生长/存档恢复，以及动态资源复用和释放。几何与上传量降低是已验证的结构收益；桌面浏览器与窄视口均不能代替手机真机帧率、功耗和温升测试。

本次验证结果：

- Farming 类型检查、内容校验、106 项单元测试、2 项离线曲线测试通过。
- 20 项开发环境浏览器测试通过；预览与农场生产构建通过，生产包另通过 2 项预览流程与 1 项种植/恢复流程。
- 实际 WebGL 下 16/64 株番茄复用既有动态 Buffer；每株更新上传 8,976 字节，静止/成熟时不上传，销毁与异步过期结果清理后存活 Buffer 数回到初始值。
- 桌面参考阶段与 390×844 视口检查通过；水稻成熟株高约增加 6 mm，穗部保留较疏的视觉近似。
- Python 与 Blender CLI 重建均产生逐字节相同的配方和图集；原始模型和图集内容未改动。

生产构建仍有原有引擎大包警告；手工浏览器的默认 favicon 请求仍为 404，植物配方与纹理加载正常。这些均不属于本次配方优化范围。
