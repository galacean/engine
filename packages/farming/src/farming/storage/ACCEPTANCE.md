## 复现

在仓库根目录运行：

```sh
pnpm --dir world typecheck:farming
pnpm --dir world farming:native-api:check
pnpm --dir world test:farming
pnpm --dir world build:farming:all
FARMING_E2E_URL=http://127.0.0.1:3016 node world/scripts/run-engine.mjs pnpm --dir world-gallery exec playwright test --config shared/farming/tests/playwright.config.ts farm-demo.e2e.spec.ts farmland.e2e.spec.ts native-farming.e2e.spec.ts storage.e2e.spec.ts water-field.e2e.spec.ts
```

浏览器回归使用真实 WebGL 与本地 IndexedDB。移动端检查是 390×844 视口，不代表真机性能或用户美术验收。测试中的延迟贴图案例冻结工具播放时钟以排除机器编译速度影响；十小时水分案例先清除杂草，隔离相应水分断言。

## 边界

- Schema 7 使用新存档身份；旧 Schema 3、4、6 的原记录保留，不迁移。
- 容器采用持久化世界坐标；不包含推车运输、手动拖动或地形修改后的自动搬迁。
- 默认数量标签面向场景首个能够看到仓储层的非离屏相机。当前验收宿主采用单个世界相机。
- 截图与本地产物留在仓库忽略目录 `output/playwright/farming-storage/`，不作为运行源码。

## 2026-10-29 马车超额库存与固定展示预算

默认保留一辆马车，取消卸货时自动增车；手动增减保留。马车支持混存和安全整数范围内的超额库存，每车只创建最多60份可见产物，超额不创建隐藏实体。仓储篮子保持既有硬容量和自动增补规则。新增回归覆盖百万份库存、混存取货后的展示替换、同版本旧多车存档恢复/手动合并、缺少车辆拒绝卸货、保存失败回滚与幂等重试。此前本文件中的“满载自动增补”“逐份创建”仅继续适用于仓储篮子。

实际本地浏览器使用独立 cart-limit-check 存档：小麦1,000,000+水稻15份恢复为一辆车、60份产物；原生 unloadBasket 再存入7份小麦、8份水稻，仍为一辆车、60份，重放未重复入库。手动2→1辆通过；出库1,000,000份小麦后剩余小麦7、水稻23，共30份且渲染30份。未改用户Seed存档。
