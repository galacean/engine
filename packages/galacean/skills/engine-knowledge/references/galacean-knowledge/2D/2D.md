# Galacean 2D（SpriteRenderer / SpriteMask / TextRenderer）

## 它是什么
- 2D 渲染能力包含精灵渲染、精灵遮罩和文本渲染，运行在 3D/2D 场景中，可与相机/光照/后处理共存。
- 通过 `SpriteRenderer` 显示图片/九宫格/平铺，`SpriteMask` 做遮罩，`TextRenderer` 显示文本。

## 简述
- `SpriteRenderer`：使用 `Sprite` 资源 + 材质（默认内置），支持 `drawMode`（Simple/ Sliced/ Tiled）、`color`、`flipX/flipY`、`maskInteraction`、`maskLayer`、`priority`。
- `SpriteMask`：使用 `Sprite` 定义遮罩形状，控制 `alphaCutoff`、`influenceLayers`，与目标渲染器的 `maskInteraction` / `maskLayer` 配合。
- `TextRenderer`：动态文本，支持自定义字体、字号、行间距、对齐、换行、溢出策略、遮罩交互与优先级。
- 阴影/光照：默认使用 Unlit 2D 材质，不受 3D 光照影响；可更换材质实现特效。

## 关联
- 资产：`Sprite`（可由 Texture/Atlas 创建）、字体资产（ttf/otf/woff）
- 组件：`SpriteRenderer`、`SpriteMask`、`TextRenderer`
- 遮罩：`SpriteMaskInteraction`、`SpriteMaskLayer`、`SpriteMask.influenceLayers`
- 渲染排序：依赖 `priority` + 相机层/队列

## 怎么用
1) 创建精灵：通过编辑器或代码从纹理构造 `Sprite`；添加 `SpriteRenderer` 并设置 `sprite`/`color`/`drawMode`。
2) 遮罩：添加 `SpriteMask`，设置 `sprite` 和 `alphaCutoff`；在目标 `SpriteRenderer/TextRenderer` 上设置 `maskInteraction` 与 `maskLayer`。
3) 文本：添加 `TextRenderer`，设置 `text`、`color`、`fontSize`、`font`、`width/height`（布局）与对齐方式；需要遮罩时配置 `maskInteraction`。

## Best Practices
- UI/HUD 场景优先考虑 UI 系统（`@galacean/engine-ui` 的 UICanvas/Image/Text/Button 等），2D 组件更适合与 3D 混排的简单平面或特效贴图。
- 若仍用 2D 组件做 HUD，建议使用正交相机+独立 Layer，配合 `priority` 控制覆盖顺序。
- 九宫格/平铺使用 `drawMode`，避免在 Shader 中缩放带来的模糊；注意像素对齐减少走样。
- 遮罩层设置需同时匹配 `SpriteMask.influenceLayers` 与渲染器 `maskLayer`，并正确配置 `maskInteraction`。
- 文本布局使用 `width/height` + `EnableWrapping/OverflowMode` 控制；需要获取真实尺寸读取 `TextRenderer.bounds`。
- 性能敏感场景复用 `Sprite` 与字体资产，避免每帧创建。

## Few-shot（常见需求提示）
- “按钮加遮罩” → 创建 `SpriteMask` 设层，按钮 `maskInteraction=VisibleInsideMask`。
- “图片九宫格适配” → `drawMode = SpriteDrawMode.Sliced` 并设置边距。
- “文本溢出截断” → `overflowMode = TextOverflow.Truncate`。
- “翻转图标” → `flipX/flipY` 或设置负缩放。

## Notes / Warning
- `SpriteMask` 仅支持 Sprite 形状；确保 `sprite` 的纹理 alpha 正确，否则遮罩边缘可能锯齿。
- 2D 默认材质使用透明混合，渲染排序仍受相机队列/priority 影响；避免与 3D 透明物体混杂导致排序问题。
- 频繁修改文本会重建网格，长段落高频更新时注意性能。
- 使用精灵遮罩需依赖模板缓冲（Stencil），需使用支持模板缓冲的渲染目标（默认屏幕缓冲已支持）；自定义 RenderTarget 时记得开启 stencil，否则遮罩不生效。
