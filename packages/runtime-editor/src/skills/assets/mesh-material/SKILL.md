# 网格与材质

在节点上配置 MeshRenderer，mesh 和 material 使用已导入资产的 {$ref: virtualPath}。

PrimitiveMesh and Material retain their Engine loader JSON formats. Engine PrimitiveMesh method signatures describe runtime mesh creation, not this asset JSON.

- 材质的字段：[材质格式](skills/assets/references/material-format.md)
