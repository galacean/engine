# M1 实现与验证

M1 基于 M0 提供米制河溪/湖泊作者编辑、真实落水、局部精细床面与原生共同发布。作者契约见 [M1_AUTHORING](M1_AUTHORING.md)，当前 PR 修复/验证见 [实施记录](../../../demos/terrain/seed-world-planner/V2_IMPLEMENTATION.md)。以下数字为 2026-10-10～12 的历史证据，不替代当前版本复验。

## 当前实现

- 一个 WaterSystem / RuntimeHost；Terrain、Water、布局、作者与撤销历史在同步接受点发布。准备读旧版，失败/取消/过期释放候选，退休清理不撤销已接受状态。
- 稳定锚点/河段/drop ID；普通坡面、集中陡坎、瀑布和阶梯分别解析，雕刻明确授权且只挖低。水帘独立几何/查询，不并入普通水深。
- Terrain 拥有不大于 5 厘米的局部细化；角色接地、生态、布局与 Water 读取共同最终床面。精细块使用实际三角插值，背景保留原契约；R16 范围统计全部未量化背景和精细顶点，再量化一次。
- 湖泊默认 1、可为 0；自然选址不足报告缺口，自动水位保留岸顶余量。凹岸/岛洞、参考湖盆、水位偏移、移动/删除与雕刻走统一 Session/schema；不填岛洞、无湿区拒绝，白盒/原生 Lake 共用实际湿岸。
- 工程保存 Seed/作者引用，统一 Runtime Project 版本与文档规范化，不加 Water 专属存档标记；不存网格/缓存或撤销栈。resolveRiver 返回未应用规划/挖低需求，宿主接受地形后发布；updateMany 原子批改。
- River 后端用共享 Look/资源实现水帘、泡沫和三类原生粒子。显隐停止/清空，恢复发射，speed=0 冻结，候选失败/删除释放拥有资源。普通无 drops 河流不加载落水贴图。
- 独立预览保留 1024 米天然水域/道路/桥与五类展示；初始选址顺应同源地形，不用加深兜底，编辑仍消费正式 Session/Worker/共同发布链。
