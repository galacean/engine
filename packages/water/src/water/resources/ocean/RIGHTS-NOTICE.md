# Stylized Water 2 source notice

This directory contains a bounded set of texture assets from Stylized Water 2 version 1.7.0 and mechanically encoded KTX2 runtime derivatives of those same assets.

The project owner has attested that explicit written authorization permitting reuse, modification, and redistribution of the listed source code, parameters, and texture assets is held privately. The authorization text is intentionally not included here. This notice does not extend to any Stylized Water 2 file that is not listed in `provenance.json`.

The Galacean runtime consumes only the bounded port and KTX2 derivatives recorded by this directory. The authorized PNG inputs remain for provenance and deterministic regeneration. Unity editor code, unrelated demo assets, meshes, and scenes are not redistributed.
