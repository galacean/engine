# Seed 动物正式资源

`assets.json` 保存 114 个模型的远程绑定与已验收的动作校准，`registrations.json` 保存素材动作语义。`PlanningAnimalContent` 叠加同级目录之外的 `animal-calibration.json` 和 `animal-behaviors.json`，不依赖动物演示页面的配置。演示目录和本机测试水池不属于正式接入的提交范围。

`remote-assets.json` 记录 121 个 GLB 外观和 22 张去重 KTX2 的 AFTS URL、SHA256、字节数及原发布校验。1024 上限、原生 KTX2、按需并行加载与 ResourceManager 复用保持不变。本轮修复发生在共享动画/运动代码和配置中，未修改 GLB/KTX2 字节；因此保留相同内容对应的正确 URL，不以重复上传或改 URL 冒充代码修复。发现、召唤接口的 `animal-types.json` 与本目录绑定保持一致。

初始化从全部 114 个模型的物种分组中按 seed 无放回抽取 14–20 种，无飞行能力动物每种默认 1–2 只；具备可用飞行动画的动物合计默认 10–20 只（`birdCount.min/max`），至少选一个有真实飞行动画的鸟种。`animal-types.json` 的 `speciesId` 合并同种模型、外观及重复素材包；`species.min/max` 控制物种数，`species.<speciesId>.min/max` 控制无飞行能力物种总数量，可飞行动物由合计额度按 seed 分配且每个选中鸟种至少一只。每只再独立抽模型和外观，默认外观等权重 1。0/0 排除物种；选中的物种数量下限必须为正，避免“已选物种却生成 0 只”的矛盾。落点失败保留诊断，不伪报已满足数量。

出生位置在全图使用按物种独立的平滑密度噪声采样，默认尺度 160 米、聚集强度 0.8；真实水陆接触、支撑和碰撞仍需通过。噪声仅影响初始化，不限制活动范围。水生种类留在水域、地面动物在陆地，鸟的飞行允许越过水面但着陆须符合其能力。256 米水平显示距离可配置，与全图活动边界独立。

显示距离外隐藏渲染；完整模拟圈为显示距离加 25%（最多 64 米），默认显示 256 米、完整模拟 320 米。所有已加载动物在圈外共用共享动物系统的任务、时钟和事件队列，仅运动采用最长 1 秒的粗采样；静止等待直接登记到期事件。近处执行原生骨骼与动态避让，远处跳过这两项，仍校验水陆支撑和落地。无鸟类专用调度、独立倒计时或宿主逐实例计时表。进入缓冲区先补齐位置并恢复同一动画相位、速度和朝向。真正禁用暂停全部任务；未加载动物不因远处模拟发起 GLB 请求，已加载模型继续使用共享缓存。初始化数量、权重、全图分布与 seed 规则不变。

水陆判定取已发布的 WaterHost 水面与真实支撑高度，alphamap 区分道路/草地/河床（河床涂层不代表积水，桥面不能当水面）。出生按注册 habitat 权重与 walk/swim 能力选择水陆，河流中心线及宽度仅用于快速候选，最终完整足迹仍检查真实水陆、地形和碰撞。地形/水域重新发布时替换候选与碰撞索引，仅对失去合法支撑的实例重新安置；无安全落点则隐藏并诊断。

动物读取发布导航的 `sampleWaterHeight`，由真实 Water Host `sampleSurface` 提供水面高度。桥面和地形接地与游泳水面分离。天气经统一真实闪电事件通知活动动物，dat.gui 和 Agent 的天气 API 共用该来源；不增加冷却。显式动物任务优先级继续高于环境反应。隐藏、未加载及禁用的动物不会因雷电加载或启动模拟。

出生偏好增加 `spawnPoint`，与草地/河流的栖息权重竞争，但不加入运行时栖息地枚举。Seed 默认仅对具备可用飞行动画的模型设置 `birdSpawnPointWeight=4`、`spawnPointRadius=96` 米，其他动物不加此偏好。底层每个 `AnimalPopulationType` 可配置 `spawnPoint: { weight, radius }`，省略或权重为 0 保持原全图采样。新增参数遵循 PlanningSession 保存/重放/重置事务，旧文档缺省取新默认，可飞行动物合计 10–20 数量不变。

每只动物按 seed 只抽一次附近倾向，概率为 `出生点权重 / (出生点权重 + 可用栖息权重之和)`（无可用权重时全图基准为 1）。选中附近后仍按素材的水陆能力和原栖息比例选择介质；水域候选必须在偏好圆内，地面/空中候选为面积均匀圆盘采样。随后仍接受密度噪声、全足迹水陆、地图边界及碰撞验证。附近尝试最多 32 次，之后回退全图同介质合法候选；不重抽附近倾向，也不保证附近至少一只。权重与圆半径只用于出生，不改变全图活动、显示距离和行为树；没有逐帧权重计算。高权重会让更多动物进入显示范围，因此可能增加实际模型加载与模拟数量。

水线按素材的真实游泳姿态校准：`waterline` 是未缩放源模型的米数，仅水中以 `水面高度 - waterline × 实例缩放` 定位，不影响陆地和空中。两款天鹅使用 0.22（默认体型约下沉 0.215 米），让脚踝在水下；鸭子、海豹和海象沿用原姿态，不统一下沉。保留鳄鱼原有 0.98。游泳停留仍使用独立的 Swim_Idle/Idle_Swim 片段。

`birdCount` 保留协议键名，但按 `canFly` 能力统计，不按生物学鸟类分类。鸵鸟、企鹅、无飞行动画的鸭/鸡归入普通物种的独立 1–2 数量范围；飞行额度中的每一个模型都必须具备可用飞行动画。

飞行的自主闲逛和受惊目的地采用 `scope: "world"`，在全图活动范围内有界抽取合法落点，不再使用固定 24–48 米航段或默认 60 秒飞行超时。无可用 Swim 的鸟只能落陆地（含离岛）；偏好水域且具备 Swim 的天鹅落水。距离由随机落点决定，可能短飞，也可能跨水域长飞；出生点偏好不参与飞行目标抽取。长航段使用 3 秒滚动预判与既有自然转向/避障，接近目标保留下降和足迹支撑验证，不预扫描整条跨岛路线。飞出模拟圈的已开始航段由每秒一次的轻量运动继续，可抵达另一座岛屿；落地后继续通过原行为树和权重选择后续活动，不再无限期休眠。

## 夏夜萤火虫

2026-11-03：萤火虫归属现有动物系统，使用程序化原生网格与材质，不增加远程模型资源，不计入 `birdCount` 或 GLB 物种额度。总动物开关也控制虫群。仅夏夜激活，季节过渡使用环境的夏季权重，时间冻结不暂停飞行。靠近地形和水面缓慢随机飞行，光核及柔光受场景遮挡和雾影响。

动物组件 v10 在 `world.animals` 下新增以下作者参数，调试面板入口为“动物分布 → 夏夜萤火虫”。UI 与 Agent 均走 PlanningSession 的 set/reset/base 事务，参数可保存、撤销及重做；旧文档缺省继承默认值。

| 参数 | 默认值 | 范围和行为 |
| --- | --- | --- |
| `fireflies.enabled` | true | 夏夜虫群开关 |
| `fireflies.maximumCount` | 96 只 | 0–256 整数；相机周边驻留上限，0 关闭 |
| `fireflies.radius` | 48 米 | 8–96 米；边缘渐隐 |
| `fireflies.speed` | 0.65 米/秒 | 0–3；0 保留静止光点 |
| `fireflies.intensity` | 1 倍 | 0–5；0 隐藏渲染 |

例如设置 `{ "op": "set", "entity": "world", "component": "animals", "values": { "fireflies.maximumCount": 64, "fireflies.intensity": 1.5 } }`。仅修改这些字段时只重建虫群，保留原有 GLB 动物和共享时钟。虫群是环境动物批次，不支持单只拾取、召唤、喂食或行为指令。持久化保存作者参数，不保存每只萤火虫的位置/随机飞行进度；离开驻留区域再返回也不保证同一条运动轨迹。当前未按植被密度筛选，水面上也可出现。
