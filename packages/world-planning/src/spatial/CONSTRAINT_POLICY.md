# 当前约束策略

以 [空间框架 README](README.md#空间可行性规则) 为唯一当前契约。

| 类别 | 行为 |
| --- | --- |
| 显式互斥体量 | 使用组合 OBB 和高度检查；局部修改固定邻居 |
| 同体量拼接 | 允许内部 OBB 相交 |
| POI 管理区、留白、密度、数量 | 生成参数/偏好；不作为全局拒绝门槛 |
| 接地 | 根据同源 Terrain 自动适配高度 |
| 占地坡度 | 用户明确新增要求；按实际 OBB 采样，可由 POI / 单体量配置上限；只在局部协调 |
| 道路 | 体量确定后搜索，失败进入诊断 |
| 数值/引用/插件契约 | 非有限值、负尺寸、坏引用、缺失插件明确报错 |

已从当前链删除村庄数量/容积率/楼层/最低建筑面积的全局约束，以及整体布局的多轮二分重试。未来建筑最低规格属于上层规则的参数契约，不能自动成为通用体量规则。
