# 动物与真实庄园

2026-10-28：专用动物庄园测试场景及独立测试 Demo 已删除。普通 Seed 与 debug 3D 共用真实庄园、项目存档和世界动物，不再预填作物/库存、额外生成动物或提供专用观察按钮。

## 真实入口

打开 `/demos/terrain/seed-world-planner/index.html?seed=1&debug=1`，点击“生成 3D”，通过已有“种植”面板选地、耕地和播种。可使用原有“前往农场”定位，或步行到庄园。该操作使用正式 Farming API 和项目存档。

动物使用 `planning-data/animal-behaviors.json` 的 eat、walk、run、idle、display 相对权重；没有额外取食门控、32米食物搜索上限或45秒驱赶禁食。未选中eat时正常闲逛，选中后保持同一有效食物目的地，交通受阻停顿后继续。返程时间取决于抽签、路程和通行情况。

真实食物来源只由 `PlanningAnimalFood(() => farming?.api)` 提供，自动跟随播种、健康、成熟度和库存变化。没有eat动画的动物不参与取食。全局出生身份保持不变，不会因播种在庄园旁额外生成动物。每个出生身份立即建立共享行为树和轻量定位实体；尚未加载模型的动物也按原权重闲逛、选择食物及移动。远处移动默认每5秒游戏时间批量推进，动作完成、交互截止和外部事件仍由共享时钟处理，不是每5秒重新抽取行为。

模型加载与逻辑模拟分离：预唤醒带至少覆盖最快注册步态在5秒内的行程，并保留原有缓冲带；进入预唤醒带请求GLB，成功后隐藏地切回逐帧，再进入显示范围。挂接沿用同一行为树、目标、位置、朝向及动画相位，加载等待不暂停远处行动。模型未就绪时不显示静止占位动物。远处仍有分步地形检查，不把更新间隔扩大等同于总CPU降低5倍。

## 移动转向

动物只随实际位移改变朝向，停止、碰撞约束或动画暂停同时停止根节点旋转。普通到达采用体长对应的容差，不吸附到目标中心；取消了原地对齐和受阻半圈旋转。贴住障碍或近处后方目标需要腾出空间时，沿经地形和占用检查的短后退弧退让；恢复进度取实际提交位移，原地失败不会反复扫描整条路线。进入驱赶动作会打断旧退让。同一目的地完成退让后回到原受阻位置，不再重复启动后退弧；真正更换目的地时重置预算，动画循环不重置。

马车的外侧路点按体型预留转弯空间，后方接近段与进食站位分开；动物在移动过程中对齐开口，最终进食同时检查站位及朝向。沿用原有高度筛选、作物与库存消费契约。

## 行为与配置

配置归属世界 `animals` 组件，使用现有作者组件编辑/事务入口，保存为 `interaction.*` 字段。默认值只有 `shared/gameplay/animal/AnimalInteraction.ts` 一处，读取旧文档时继承默认值；修改这些值不重新抽取动物出生身份。

| 字段 | 默认值 | 实际行为 |
| --- | ---: | --- |
| `interaction.approachDistance` | 3 m | 角色在范围内快速靠近时触发轻度避让；0 停用 |
| `interaction.approachSpeed` | 1.8 m/s | 朝动物方向的接近速度阈值；经过、远离和相机瞬移不触发 |
| `interaction.approachCooldown` | 5 s | 限制连续轻度威胁，避免每帧重启行为 |
| `interaction.clickDistance` | 5 m | 近距射线命中且未被实体遮挡时驱赶；0 停用 |
| `interaction.biteDistance` | 1.5 m | 普通作物/果篮停靠距离上限，结合模型长度缩小；0 停用 |
| `interaction.minimumCropMaturity` | 0 | 可食作物成长比例下限，0–1，包含边界；健康必须大于0 |
| `interaction.feedingSeconds` | 10 s | 连续进食的游戏时间；循环真实 eat 动画，中断后重新计时 |
| `interaction.feedingReachHeightRatio` | 1 | 可触及高度为实际标定动物身高乘此比例；按目标处地面计算，避免拒绝上坡目标 |

快速接近使用当前介质已注册的慢速步态（陆地优先 walk）。点击与打雷复用同一 startle 行为，按已有逃离权重和可用介质选择 run、swim 或 fly 等真实动作，因此水中的鸟也能游开或起飞。点击驱赶保持请求的快速步态，不受普通移动的低速降档影响；交通受阻仍可停止等待。目标远离威胁来源并通过既有支撑、障碍和群体约束。点击能打断显式进食任务；普通靠近保留显式命令优先级。驱赶只是玩法威胁，不新增动物生命值或伤害战斗系统。

庄园玩法按真实eat动画开放，所有eat模型均可随机选择有效作物和果实，没有食谱、食物分类或作物白名单；没有eat的模型不参与庄园倾向。当前最低成长比例默认0，因此刚种下的健康作物也可食；设为1才只吃成熟作物。连续进食10秒完成后，重读当前作物健康，通过 `damageCrop(source: animal)` 将剩余健康全扣到0，复用已有 crop-removed 与植物清除逻辑。选择下一目标仍由自主行为决策；行走和等待不计入连续进食时间。

落地果篮通过 `consumeBasket` 原子命令每次减少1个指定果实；马车通过带 `containerId` 的 `withdrawInventory` 精确扣指定容器。两者也须连续进食10秒。果篮内容网格随库存重建，马车原有表现逐个销毁减少的果实Entity；空篮不隐藏整个篮子。动物根据真实货物槽高度与自身标定身高判断可达，不可达容器不会阻挡其他可食目标。携带、搬动、换株、耗尽或版本改变都要重验；明确版本冲突只重验并重试一次，存储失败不自动重试。中途驱赶不扣，已完成的一口不会被后续点击撤销。食物目标在连续进食期间绑定身份，不能把对上一目标的计时挪给新目标。

`animals.minimumEatingAnimals=2` 保证默认生成请求中至少两只有真实eat动画的动物；32个eat模型参与同一保底池。旧字段仅在文档迁移时读取，组件版本为9。配额在已有物种数和每种数量上限内分配，显式0/0排除仍有效；配置不可满足时报错，不突破用户上限。几何出生候选仍须通过，实际生成数由Seed运行时核验。

## 表现与验证边界

作物健康归零会走原有 `crop-removed` 链路；植物保留约2秒 dissolve 退场后释放。果篮减少内容网格，推车删除减少的果实实体；篮子与推车本体保留。推车高度取当前货物槽的真实高度，而非容器底部。高度是轻量玩法筛选，不承诺每种原生动画的嘴部精确接触。循环动画不重置一口的10秒，驱赶和目标失效取消计时，不会将旧目标计时转移给新目标。


原生 Farming 声明及 Seed 快照同步本轮6个 Farming 条目；基线已有13个非 Farming 陈旧条目未混入本次修改。



点击驱赶与雷声使用快速响应：保持逃跑步态，短过渡/加速并加快转弯；Seed雷声不再随机选择walk。正常闲逛/轻度靠近保留原参数。真实Seed野牛雷声样本在首帧约16ms切run，0.2秒位移0.32米；沿途碰撞仍可能要求等待，不承诺穿过阻挡立即离开。

取食途中原目标被收割/耗尽：发现变化后，有其他有效食物就同步改用新的移动目的地，无食物则结束取食移动并回到自主选择；交通等待不清除仍有效的目标。食物发现有缓存与行为检查间隔，变化不是同帧生效。
