# Terrain demo · Stage 1

T3D-style terrain rendering on Galacean's forward pipeline:
- **heightmap** (R16 unorm, disk file)
- **controlmap** (32-bit bitfield per texel — base/overlay id, blend, uv rot/scale, hole, nav, autoshader)
- **Texture2DArray** of CC0 PBR layers (grass + rock)
- **Consumer** system that lets external subsystems (water-pcg, foliage, …) plug into terrain data

Design + roadmap: [`world-gallery/terrain-reference/design.md`](../../terrain-reference/design.md).
Water-pcg integration writeup: [`terrain-reference/water-pcg-integration.md`](../../terrain-reference/water-pcg-integration.md).

## Data

Everything under `data/` is checked-in disk fixture:

```
data/
├── manifest.json                    — regions + layers metadata (dimensions, elevation range,
│                                       bit layout — no separate .meta.json files)
├── regions/
│   ├── heightmap_0_0.r16            — raw Uint16 little-endian, 1024²
│   └── controlmap_0_0.bin           — raw Uint32 little-endian bitfield, 1024²
└── textures/                        — CC0 PBR layer packs (Terrain3D's demo assets)
```

The two binary fixtures are generated by `tools/bake-region.mjs` (offline PCG). Replace the two
files with real DEM output (e.g. Tangram Heightmapper PNG16 → converted to `.r16`) and the runtime
loader rehydrates from `manifest.json` without any code change.

### Rebaking

```bash
node world-gallery/demos/terrain/tools/bake-region.mjs
```

Prints the manifest snippet to paste back into `data/manifest.json` if dimensions / elevation
range change.

## Architecture

```
main.ts
├── TerrainMaterial       — global layer library (Texture2DArray + uv scales + autoshader / debug switches)
├── TerrainRenderer       — MeshRenderer subclass, per-tile ShaderData (heightmap, controlmap, tile size)
├── TerrainSystem         — consumer registry + query context; broadcasts data-change events
│                           to registered consumers
└── WaterPcgConsumer      — bridges TerrainSystem → water-pcg OceanPreview. Sizes + positions
                            the ocean mesh from findRegionsByLayerKind(Water). Subscribes to
                            HeightMap events so the surface Y follows live min/max slider drags.
```

Any future subsystem (foliage, cliff, building, lighting) plugs in via
`terrainSystem.registerConsumer(...)` and picks the `interests[]` events it wants.

## Shader properties

Prefix convention follows Galacean's `packages/shader/src/Shaders/PBR.shader`.

* **`renderer_*`** — per-tile ShaderData: `HeightMap`, `ControlMap`, `HeightRange`, `TileSize`,
  `HeightTexelSize`. Lets many tiles share one material.
* **`material_*`** — global material uniforms: `LayerAlbedoArray`, `LayerNormalArray`,
  `LayerUvScales[8]`, `LayerNormalIntensities[8]`, autoshader (`AutoSlope`,
  `AutoHeightReduction`), debug (`DebugMode`, `DebugLayerId`).

## Debug affordances

* **dat.gui** (top-right):
  * `地形几何 Heightmap` — min/max metres + tile size, all live.
  * `Autoshader (T3D)` — auto slope + height reduction (only affects texels with controlmap bit 0 = 1,
    i.e. right half of the island in the current fixture; left half is painted mode).
  * `外部系统 Consumers` — water-pcg on/off.
* **Debug thumbnail wall** (bottom-left, see `src/debug/AssetOverlay.ts`) — card per data source
  (HeightMap) and per controlmap bit-field (autoshader / nav / hole / uvScale / uvRot / blend /
  base_id / overlay_id / per-layer masks). Click a card → whole scene renders that field via the
  shader's debug mode. Header has `⊗ 退出调试` to restore normal rendering.

## E2E visual regression

Local to the demo — no engine e2e harness, no baseline JPEGs uploaded to git-lfs.

```
world-gallery/demos/terrain/e2e/
├── visual-diff.mjs             — playwright + odiff; drives 7 variants via material.setDebug/…
├── baselines/*.png             — reviewer-approved (checked in)
├── downloads/*.png             — gitignored
└── diff/*.png                  — gitignored
```

Regression run:
```bash
node world-gallery/demos/terrain/e2e/visual-diff.mjs                 # compare
VDIFF_UPDATE=1 node world-gallery/demos/terrain/e2e/visual-diff.mjs  # rewrite baselines
```

Requires the world-gallery dev server on `http://127.0.0.1:3777`. `PROBE_URL=…` overrides.
