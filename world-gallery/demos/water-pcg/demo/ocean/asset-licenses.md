# Ocean Beach Dusk asset manifest

All files below are bundled locally. The runtime does not depend on a remote
asset service.

| Asset | Source | License / ownership |
| --- | --- | --- |
| Beach and sea-bed mesh | Generated at runtime from `OceanBeachShowcasePreset.ts` | Project-authored code and data |
| `assets/beach-sand-albedo.png` | Project-generated photographic-style, seamless beach-sand base color using OpenAI image generation on 2026-07-24; deterministic normal, roughness/metallic and AO maps are derived locally | Generated specifically for this project |
| `assets/coastal-granite-albedo.png` | Project-generated photographic-style coastal-granite base color using OpenAI image generation on 2026-07-24; deterministic normal, roughness/metallic and AO maps are derived locally | Generated specifically for this project |
| `assets/rock-07/**` | Poly Haven [Rock 07](https://polyhaven.com/a/rock_07), 1K glTF with diffuse, OpenGL normal and ARM textures; author Jenelle van Heerden | [CC0](https://polyhaven.com/license); downloaded through the official Poly Haven API and stored locally |
| Hero rocks | Three transformed instances of the shared Rock 07 glTF; the ARM red channel is additionally bound to Galacean PBR occlusion | CC0 source above |
| Dunes, shoreline stones and distant boat | Galacean `PrimitiveMesh` or project-authored deterministic mesh geometry with project-authored PBR parameters; the final view intentionally omits the former low-detail cliff and lighthouse placeholders | Galacean Engine repository license and project-authored code |
| Sky and sun disk | Galacean `SkyProceduralMaterial` | Galacean Engine repository license; the shader file retains its upstream Unity Companion License notice |
| Water dual-slope micro-detail texture | Deterministically generated by `WaterSurfaceDetailTextureFactory.ts`; RG and BA contain two independently advected linear slope fields | Project-authored procedural data |
| Foam micro-detail texture | Deterministically generated by `WaterFoamDetailTextureFactory.ts`; RGB contain independent thick, medium and light coverage masks | Project-authored procedural data |
| Temporal foam, wet-sand and nearshore textures | Deterministically generated runtime fields | Project-authored procedural data |
| Splash particles | Galacean `ParticleRenderer` with project-authored parameters | Galacean Engine repository license |

The RG/BA slope packing and layered RGB foam semantics were independently
implemented after studying water-rendering techniques in the local
`com.unity.urp-water-system` reference package. Its Unity Companion License does
not grant a general-purpose Galacean redistribution right, so this Showcase
copies neither that package's texture pixels nor its URP shader code.
