## Offline derivative record

The five sand derivatives were produced with macOS `sips`, using `-z <size> <size> -s format jpeg -s formatOptions 90`. The original files remain in `/Users/xingyi/Documents/data/water-system-assets/ocean-beach`; only the smaller derivatives are bundled. At runtime the authored Ground055S Roughness red value is remapped into a bounded dielectric sand range and packed into Galacean's roughness/metallic G channel, while metallic B is fixed to zero. Ambient occlusion remains a separate linear texture.
