# 100款动物行为观察场

打开 `/demos/animals/roaming/index.html`。默认加载新采购的100款模型（包含配色/幼体变体），全部自主闲逛。已移除旧 Farm 素材、配置及预览入口。

## 观察与校准

- 原始米制比例统一 scale=1，不按动物大小归一化。地面每格1米。
- 点击模型或下拉框选择；“观察这只”拉近并持续跟随，“查看全部”退出跟随。
- 右侧显示面数、关节、尺寸和动画；模型比例/移动倍率仅调整当前实例，刷新复原。改变比例同时缩放移动速度，移动倍率可单独用于脚滑校准。
- 名称默认隐藏，没有选中圆盘；阴影默认关闭，可切换观察额外开销。
- 原始动画下拉框进入单实例手动预览，播放一次后保持末帧；下达指令恢复行为树。

## 枚举与配置注册（2026-10-15）

当前100款的唯一行为配置入口为 `registrations.json`：40份物种/玩法定义和100份模型注册，覆盖441段片段。旧 `behaviors.json` 不再使用。

共享 `AnimalRegistration.ts` 定义 AnimalActivity、AnimalGait、AnimalMedium、AnimalPosture、AnimalHabitat、AnimalSemanticEvidence 以及目标查询/条件枚举。JSON使用枚举的字符串值，注册时校验拼写、物种引用、片段覆盖、动态移动能力和权重；模型/物种ID保持可扩展的内容身份。

`registerAnimalCatalog()` 将配置编译成现有 AnimalTaskController 配方。LLM仍然只看到 idle/moveTo/startle，语义枚举及clip不进入公开命令。

- `species`：栖息区域偏好、自主任务权重、常规/逃离步态优先顺序。配色和幼体共用；需要不同规则时另设定义或模型绑定。
- `models`：assetId、species、初始放置半径和逐片段的 activity/medium/gait/posture/evidence。
- `Lama_Gesture` 在美洲驼注册中明确为 eat + ground，原始片段名不修改。其他未确认Gesture和普通Jump保持 unclassified，仅可手动预览。
- `eat`先检查食物存在，移动到食物附近，再检查取食距离；进食资格只取决于真实eat动画。关闭“测试食物可用”会唤醒行为树，取消失效的取食分支，明确移动等其他任务不受影响。

示例（截取 `lama-02`，使用枚举序列化值）：

```json
{
  "assetId": "lama-02",
  "species": "lama",
  "spawnRadius": 0.35,
  "animations": {
    "gesture": {
      "activity": "eat", "medium": "ground",
      "evidence": "reviewed"
    }
  }
}
```

完整注册必须覆盖全部clip；上面仅演示绑定方式。修改 `registrations.json` 后刷新即可，不需要改行为树执行器。`tools/register-low-poly-animals.py` 是初始配置生成工具，会覆盖配置；人工标注后的JSON是内容源，不应在日常启动时重生成。

## 动画语义与行为配方

`animals.json` 保存真实clip、尺寸和校准；`registrations.json` 保存含义与偏好。标签从注册语义生成，不把原始Gesture统一翻译成“展示”。未标注动作不会进入自主抽签。

所有状态使用 WrapMode.Once，不读取源循环标志。每段实际完成后唤醒行为树，自主行为重新抽签；同一动画可能再次被选中。明确移动任务保留目的地，每段结束重新选择该移动阶段允许的动画，直到抵达、被新指令取消或超时。自主移动设置 cycles=1，每段结束返回自主选择器。停留、已标注表现、坐姿、卧姿可按配置参与闲逛；进食另有食物与距离条件。

98款具备有效Walk。成年熊猫的Walk全静止，自动移动使用Run；袋鼠没有Walk/Run，使用Jump。Fly/Swim保留手动预览，地面自主配方不选择它们。

闲置是自主模式，回执立即完成，不占明确指令优先级。明确指令 > 环境反应 > 自主行为；新指令取消旧任务。打雷按钮向全体下达明确受惊指令，连续点击立即重播，没有冷却。公开任务仍为 idle/moveTo/startle，LLM不接触原始clip或动画语义ID。

## 转向与片段完成

本批没有独立转身片段，当前使用程序转向：根据体长、标称步速和上一子步实际移动速度确定转弯节奏（动态上限不超过0.12 + 实际速度/(体长×1.25) rad/s），绝对上限0.3 rad/s（约17.2°/s），角加速度不超过0.3 rad/s²；转弯或避让减速时进一步降低转向上限，紧密交通中只保留较慢的小步转身能力；位移沿身体朝向形成弧线，不直接沿目标向量侧滑。转向时同时减速并调整步态播放率，结束事件按真实动画进度触发。跨片段使用 `crossFadeInFixedDuration`，默认0.4动画秒（极短片段最多其时长的50%）；sit/lying可直接混合到walk，不要求额外起身动画。原先 `crossFade(..., 0.35)` 实际表示目标片段时长的35%，旧文档对单位的描述有误。

实际转向、脚步接触和坐卧混合观感仍需用户验收。移动速度来自低位脚骨轨迹的估计，不宣称逐模型无脚滑。

### 步态与根运动同步修复（2026-10-15）

移动action通过 `play(clip, locomotionSpeed)` 明确告知当前片段支持根运动；等待idle和普通animate不附带该能力。LLM指令无需新增字段。`AnimalMotionPlayback` 将一次片段的剩余时间、步态速率、混合进度与移动许可统一计算；共享crowd在碰撞求解前消费许可，静止/已结束片段保持根位置和朝向。原生脚步确实推进后才允许根运动；物理加速独立于crossfade权重，避免每次短步态重播重复压低速度；明显转向时步态速率不低于0.65倍。处理引擎play/crossfade当帧只求值time=0的规则，防止动画时钟抢跑。

等待行为树预算期间不能移动冻结的姿态；没有将片段改成循环，也没有由展示层选择动画。idle堵停时依然计算候选路线，所以通路恢复可以唤醒树并重启步态，不会因禁用根运动而永久堵死。快照 `motionSync` 累计记录移动子步及其中没有推进步态的违规子步。该计数验证运行时同步，不等于逐脚掌接触/IK验证。

后续转向跳变修复：抵达目标朝向时保留连续累积角，不将其重新写成atan2的[-π, π]值；否则跨0°/360°时，步态混合会把整圈差值当作真实旋转。回归用例在修复前复现单个1/60秒子步转179.86°，修复后为0.143°。`motionSync.maxTurnDegreesPerSecond` 由实际朝向差计算，避免仅检查角速度字段而漏检。证据：`evidence/2026-10-15-continuous-heading/`。

本修复没有新增或伪造转身素材，也没有同时叠加两段互相覆盖的全身动画；当前为程序转向与注册步态同时执行。进一步的专用转身步态、足部IK和逐模型无脚滑仍未实现。复核证据：`evidence/2026-10-15-turn-gait-sync/`；此前避让测试不能作为本缺陷已通过视觉验收的证据。

## 动态避让与碰撞（2026-10-15）

`GroundAnimalCrowd` 是无渲染依赖的共享移动世界，接受米制位置、圆盘半径、体长、速度和目标，不读取模型路径或动物种类。`AnimalSystem.addMotionStep()` 在每个不超过1/60秒的模拟子步先推进共享移动世界，再更新各实例动画；暂停同时冻结两者，没有每动物计时器。

空间网格复用桶和邻居数组，查找附近动物；候选方向包括原有12个目标相对方向、当前朝向、上一避让方向和4个前向缓弯方向，避免慢速转向时丢掉可继续走出的路线。评分结合2.5秒内的相对运动、近距离离开方向、目标方向、上一避让方向和角动量；候选方向复用实际刹车限速判断，避免选择会被刹停器永久禁止的路线，优先保持绕行侧。转向沿用体长/速度相关的角速度和角加速度限制，位移始终沿身体朝向。前方空间和刹车距离控制减速；在步态仍有效时取消移动会逐步停稳；行为树切到静止姿态后，姿态约束立即锁住根位移与朝向，不能在idle下继续滑行或旋转。

所有动物先提出位移，再统一求解连续圆盘接触，限制会穿透的位移；不把已经重叠的动物瞬移推开。极端情况下已无刹车距离时，安全约束会直接停住，优先防穿透。静止、卧躺和手动预览的动物仍是障碍。初始重叠和会造成重叠的放大操作明确拒绝。

前路被占据且停稳后，通过状态变化唤醒行为树，移动action在当前步态结束后按注册idle权重播放一次等待动画，保留目标和任务优先级；空间恢复后立即切回注册步态。片段依旧全部Once，无冷却，不让渲染器自行循环或随机选动作。转弯时仍用步态表现脚部运动。

当前使用覆盖各片段采样包围盒的保守圆盘，长尾/长鼻动物会留出较大空隙。它保证的是配置轮廓的分离，并非精确身体接触。局部避让不承诺在无法通行的密集包围中找到全局路径；不可达目标仍遵循原任务超时与取消机制。地形/建筑导航、飞行避让和Seed接入未在此轮实现。

右侧展示避让耗时/步、等待数量和运行以来邻居对的最小轮廓间距；“运行快照”另做一次完整4950对间距审计，避免把全量审计放进每帧。历史间距使用运行时已有邻居对累计，记录本轮实测。

## 性能与边界

100款合计175496个三角面、3342个关节。Demo把相同色板提取成共用远程KTX2（实际GPU纹理共享在运行快照中核对），原始独立GLB仍自包含。渲染像素比上限1.5，默认无阴影；隐藏名称时不进行100个标签投影和DOM写入。行为树由统一模拟时钟和事件唤醒，不使用每动物setTimeout/setInterval。默认决策预算32次/帧；运动/动画按帧推进。

右侧显示最近300帧FPS/p95，以及模拟更新耗时；“运行快照”可采集100实例状态、播放次数、几何量、纹理共享数量和原始帧间隔。模拟耗时包含动画与转向，不代表整帧CPU或GPU时间。

当前平坦场景含六个测试栖息区域及可开关的食物区域。初始放置消费栖息偏好，并用覆盖已采样动画包围范围的保守碰撞半径检查间距。加载前统一规划全部位置，大模型优先，遇到区域碎片化时整组重试；测试栖息区扩大为原来的1.25倍，地面为80米见方，保持模型原始比例。自主目标保持在选定区域中。栖息标签与食物偏好是Demo人工玩法预设，不是经动物学验证的真实生态范围，未模拟温度/湿度/昼夜。

已接入地面动态避让与连续圆盘碰撞约束。仍没有刚体/网格物理碰撞、资源消耗/饥饿满足、真实饮水、飞行/游泳移动、自动LOD或Seed接入。食物区只提供条件，不宣称播放进食后已经消费草地资源。原比例尚未逐物种确认；桌面短时检查不代表移动设备或Seed大世界性能验收。

### 2026-10-16 动画混合连续性

手动切换、同片段单次播放完成后的重播、快速walk→idle→walk都进入同一原生crossfade路径。每个片段预建3个共享AnimationClip的状态绑定，新目标避开当前原生源/目标状态；连续指令立即从当前显示姿态转入新目标，不通过直接play重置姿态。初次构造使用play，显式时间轴seek仍直接定位。GLB、贴图和动画曲线不复制，也不运行多个Animator。

混合默认0.4动画秒，短片段最多占其时长一半。所有片段仍WrapMode.Once，结束唤醒行为树，位移仍必须有真实步态推进；移动片段混入时先验证姿态推进，再按物理加速推进根位移。运行快照的motionSync新增crossfades/directPlays/blendSeconds/nativeTargetState，用于区分混合、初始播放和主动seek；nativeAnimation仍展示原始语义片段ID。没有新增面板。

### 2026-10-16 指令位移与慢速转向修复（本地）

受惊逃离距离由有效逃离步态速度×5秒计算，并约束为8–24米，不再使用网格半径×5。场景边界处尝试有实际逃离距离的有界方向，避免简单clamp得到近零位移。去河边保留当前位置的横向坐标，岸边位置留出实例保守半径；不再按序号安排横穿全场及1.3米密集行列。避让停步只在步态结束后选择idle，通路恢复立即切回步态；明确新指令仍立即打断，没有冷却。完整验证结果见规划实现记录与外部证据目录。

### 2026-10-16 野牛切换动画时快速翻身的素材根因

Bison_Walk的整副加权骨架相对Idle/Run约反向180度，旧整模型yaw=180仅让Walk面向移动方向，却使Idle/Run反向；0.4秒混合会真实旋转骨架，而根节点转速诊断看不到。修正由tools/clip-facing-corrections.json显式声明，tools/normalize-clip-facing.py在导入期将Walk骨架根的旋转、位移统一到相同模型空间；野牛整模型yaw同步为0。修正输出仍是一个GLB，复用同一贴图，没有每帧校正骨骼的补丁。import-unity-pack.py已接入规则，重导不会丢失；原始采购素材不覆盖。原网格/蒙皮/贴图和其他片段的原始二进制保持不变，修正采样另存，GLB增加1772字节。

普通转弯另将最高角速度降为0.3rad/s，并降低角加速度，朝后方转弯时保留半速前进，再由近目标/避让约束减速。共享Crowd补充4个当前朝向附近的缓弯出口，仍使用原扫掠碰撞与姿态许可。单独原生验收入口/shared/gameplay/tests/runtime/turning.html使用相同目标、机位、比例、60Hz步长及真实GLB，可逐模拟秒推进；不向Seed或本Demo增加面板。证据动图为每模拟秒一帧，原数据记录每0.1秒，根速度和骨架可见朝向分别统计；不把动图帧率当作浏览器FPS。
