# 峡谷轮廓覆盖辅助实验

入口：`canyon-shape-study/index.html`。同屏展示原图与描绘边界、固定目标多边形、未裁剪 OBB 和误差。启动时自动在 worker 中拟合，无需手工接入。

目标数据来自用户参考图的人工描绘，单位为图片像素，不等于图片分割真值或真实素材尺寸。通用拟合模块不引用峡谷坐标或 seed。

测试：CanyonShapeFit.spec.ts，3 项通过。每岸覆盖率必须 >90%，越界率 <0.2%，每岸最多160块，边长12–180像素，长宽比不超过4。面积通过边交点分段积分计算，独立于拟合栅格，重叠只算一次。包含重复矩形、超大矩形、旋转交集、预算不足负例。当时实测左岸94.5743%（35块）、右岸94.6021%（56块）；历史 coverage-result.json 与 target-contours.svg 导出已清理，已提交版本可从 Git 历史追溯。当前可通过页面重新计算并导出，原 reference.png 仍是本研究页面使用的参考输入。

最新方向：本实验仅验证多边形近似能力，不证明峡谷 A/B/C 空间结构、素材适配或审美成立。用户提出转向具有职责的白盒组合；不将精确描边和覆盖率作为峡谷生成主目标，不接入全局规划器。
