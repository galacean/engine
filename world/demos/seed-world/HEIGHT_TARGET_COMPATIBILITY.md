# 实测高度目标与旧存档兼容方案

2026-11-01：本次只澄清现有幅度契约；下述实高目标接口是待实施方案，尚不可调用。

现状：procedural landform 的 elevationDelta 是形状幅度。采样值还乘以非对称、粗糙度、侵蚀等因子；不保证最高点相对基准地表增高相同数值。它也不是山顶海拔。compact-cosine hill 的 peakRelief 保持自己的既有契约。

兼容边界：不改现有持久化字段、版本、Seed、采样器或老文档重放行为，不批量归一化旧地形。无新目标字段的文档仍使用旧幅度算法；旧档同一位置与地形指纹必须一致。新增能力不能靠读档时静默重算改变旧世界。

建议新增显式目标 peakDeltaMetres（命名需随正式 schema 审查），定义为本次地形影响范围内，相对于应用该特征前基准地表的最大增高；负值需另定义 minimumDelta，不能复用“最高点”含糊表达。绝对海拔目标使用不同字段。只允许单一目标或单一幅度，冲突输入明确拒绝。

求解由作者事务处理：在实际消费网格和完整影响范围上测量单位幅度的输出，再求所需幅度并验证；涉及地形裁剪或其他非线性时有界求解，无法达到则返回目标未达及误差，不修改邻居或放宽要求。记录作者目标及求解后的幅度，不持久化生成网格；算法版本跟随项目既有版本管理。已有旧档如需实高目标，由用户显式编辑触发。

回执分开提供 requested（目标、单位、基准）、resolved（幅度）、measured（基准修订、网格间距、极值位置、实测增高与误差）和 achieved。写入已接受、已发布、实测达标分别表达；不能回显参数充当测量。真实查询应能复核同一基准；不可测时明确未验证。

验收：保留原 #51 输入作为反例，幅度 3/5 的旧几何仍为原结果；新增目标在多个 seed、粗糙度、侵蚀、坡底与网格对齐下实测达到公开容差。验证旧档重放与无关地形不变、事务失败回滚、保存重开、正负高度边界，以及碰撞/导航消费相同地表。容差依据最终网格和量化精度声明，不能由检查器临时放宽。
