# 农场平整土地层

复用本地 `farmlands-viewer/Assets/Polyart/PolyartStudio/Farmlands` 的 `M_Farm_DirtFlat` 风格和 `T_Farm_Dirt_Flat_C/N.tga`。保留来源资产原有授权边界；没有修改参考 Unity 项目。

原图均为 2048²。运行时仅加载 512² 颜色图（sRGB），采用 UASTC + Zstd、完整重复寻址 mip 链，世界坐标每 4 米重复。256² 法线保留为压缩产物，当前河岸同源着色路径不加载它；法线、粗糙度、光照和气候均复用原生地表路径，不带入 2K 高度图、ORM 或视差遮蔽。来源与产物 SHA-256、尺寸和文件字节数见 `manifest.json`。

重新生成：`python3 world/gallery/demos/terrain/scripts/encode-farm-land-textures.py /path/to/farmlands-viewer /path/to/ktx`（Pillow、KTX-Software 4.4.2）。

土地层只属于 Planner 表现，仅由已提交耕地向外扩展 3 米，整段使用与河岸相同的五次平滑距离权重。局部 R8 遮罩间距不超过 0.1 米，在像素中采样；边界外使用欧氏距离，让拐角自然圆滑。推车/篮子不产生泥土，而是明确的草地保留区；遮罩为其保留一格采样保护距离，再在 0.35 米内恢复邻近泥土权重。操作通道也不产生泥土。

渐变带复用世界地形的颜色场、Alphamap、河床混色与虚拟地表法线，在同一地表路径中混色后进行光照；不会在两套已经照明的表面之间淡化透明度。调色、季节、地形资源更新跟随原有世界绑定。完全泥土区域跳过草地近远颜色、道路与河床底色计算，仍保留法线和气候需要的 Alphamap 采样；土地片元只读取一次覆盖权重，泥土颜色在分支前采样以保持 mip 选择连续。保留三层结构和现有植被占地清理，未改变种植状态、河岸参数或 Terrain 的作者权重。

土地网格与原始高度网格同间距（当前约 1 米），每块 8×8 个原始单元，保留 Float32 顶点坐标与原始三角形方向；仅上传位置与法线。遮罩独立保持 0.1 米精度，按矩形影响范围栅格化最近距离，避免每个像素重复遍历全部地块。布局变化仅重烘焙受影响遮罩并复用网格；同一高度网格的刷新只比较各块 121 个高度样本（含法线邻域），不复制全世界字段、不重烘焙遮罩，只替换实际高度发生变化的网格。

图集使用稳定槽位，布局未变时仅上传脏遮罩；增删分块才更新页表，扩容时才整体搬迁，删除分块复用空槽。容量通常翻倍，在设备最大纹理边长与双字节页码的有效范围内收紧；列数、行数及页表均在 GPU 分配前校验。超限先报错，不改变已接受的槽位、绑定、网格和遮罩；土地所有者在修改分块前执行同一预检。预留容量换取连续增种时的稳定上传量，清空或关闭时释放。

图集和页表注册共享的 `restoreResource` 内容恢复配方，读取当前驻留瓦片及页表；土地网格恢复时使用已缓存的局部高度重建顶点与索引，不增加全世界副本或常驻的额外打包数组。恢复绕过正常更新的 dirty/signature 判断，只在设备恢复时重传内容；销毁与替换资源同步移除其恢复器。分块移除或系统关闭时释放自有网格、图集和材质，同时解除借用的世界表面绑定。
