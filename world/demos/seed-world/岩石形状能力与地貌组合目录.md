# 岩石形状能力与地貌组合目录

状态：2026-09-15 用户修正后的设计基准，未实现的能力不能根据此目录推断已可用。取代“六类职责就是六类不可拆原子”的假设；先前单文件 HTML 是旧实现快照，仍需依据本设计改版。

## 形状、职责、地貌分开

一个岩石实例表达一个实体形状，其内部允许少量 OBB 粗略表达体量。冠峰不是固定居中的四层阶梯，岩壁不是固定朝向的七段柱子。形状定义包含连续参数和构造规则，而不是唯一中心、尺寸或盒子排列。

形状职责由地貌实例赋予：同一楔体可以做山肩、突出岩嘴、台地边缘或山脚过渡；同一冠峰可以是主峰、次峰、山口支点或视线目标。地貌组合引用共享形状目录，并决定位置、尺寸、相互关系和留白，不复制形状实现。

鞍部/缺口退出单岩石原子目录。其基本组合是两个峰体（冠峰、尖峰或圆丘均可），加中间低口/净空；可选低基座。不能只用“两峰相邻”这个名字证明低口或通路存在。台地地貌也不等于单个平顶石：平顶石可参与承托，完整台地由顶面、边壁和接地关系组成。

## 单块形状能力：五个基础构造族

这些是实现抽象，不是五种固定美术造型。预设均共享下方连续参数；变体不需要复制算法。

| 构造族 | 核心能力 | 可提供的命名预设 |
|---|---|---|
| 块体 | 宽厚实体，边界与顶部可调；单峰顶或宽顶 | 普通块石、圆丘、冠峰、偏峰、平顶岩、扁平基岩 |
| 收束体 | 底部到顶部独立收窄，顶部可偏移 | 尖塔、矮尖岩、柱峰、偏斜柱峰 |
| 板体 | 两个较大方向与一个较薄方向，可改变姿态 | 厚岩壁、薄岩片、竖向岩鳍、水平盖板 |
| 楔体 | 一端厚高、一端薄低；可改变坡向与两端宽度 | 山肩、岩嘴、缓坡块、山脚裙边 |
| 脊体 | 沿短骨架延伸，截面与高度沿程变化 | 直脊、弧脊、扭转脊、折脊 |

22个命名预设并不代表22份实现；未来程序化岩石能力不足时，可限制相应预设参数，或在组合层改用多个更简单的岩石。脊体不是要求已有素材贴合任意长曲线；当前应有曲率和长度预算，超出时分段。普通无形状要求体量仍为单OBB。

## 每个实例必须具备的可变能力

- 米制尺寸：独立 width/depth/height，配置默认比例与可实现区间；不把高度绑定到一个固定中心。
- 位姿：世界位置、底高、朝向；需要斜岩/岩鳍/盖板时扩展俯仰与侧倾。当前 V2Box 仅支持 yaw，不能假称三轴已经实现。
- 峰顶：平面位置 peakU/peakV、顶部宽度、尖钝程度、顶部相对基底偏移；归一化位置由配置给出，实际坐标从尺寸解析。
- 截面：底部/中段/顶部的宽度和进深比例，沿高程或骨架的变化；每个预设可以限制无意义或不可实现的组合。
- 两端：楔体与脊体的首尾高度、首尾宽度；高端低端可交换，延伸方向可旋转。
- 边界：各侧陡缓、坡脚外展量、前后不对称、侧向弯曲；不使用随机抖动代替结构形状。
- 实现预算：最大构件数、最小厚度、允许缩放、倾斜和嵌入范围。形状参数超出支持域时明确拒绝或返回需要组合拆分，不能偷偷夹紧到另一个形状并声称成功。

每种形状并非暴露所有参数：统一底层描述，但仅支持与本构造族有意义的参数。预设只是默认值。形状参数不是编辑器上的用户语义滑杆。

冠峰示例：同一构造族可以实例化居中宽冠、偏左矮冠、偏后高冠。三者由同一编译器处理，分别具有峰顶位置、峰顶宽度和实际高度；不能为每个实例写一份专用 OBB 坐标。生成后从实际 OBB 校验目标尺度，必要时在形状预算内增加构件。

## 地貌组合目录：首批三十二种

| 结构 | 可复用形状 | 必须表达的组合关系 |
|---|---|---|
| 单峰山 | 冠峰、楔体 | 主体与坡脚过渡 |
| 主次峰群 | 冠峰、尖塔、圆丘 | 主次高度、前后深度和间隔 |
| 双峰 | 两个峰体 | 两峰间隔，轮廓可辨 |
| 鞍部 | 两峰、可选块体基座 | 中间高度低于两侧，上方净空 |
| 山口 | 两侧峰体/岩壁、楔体 | 穿越留白与两端展开 |
| 峰林 | 柱峰、尖塔、基岩 | 密度分区、峰间通道 |
| 石林通道 | 岩鳍、柱峰 | 曲折但连续的穿行留白 |
| 长山脊 | 脊体、冠峰 | 纵向延展与高低节奏 |
| 锯齿山脊 | 尖峰、短脊 | 交替峰谷与方向延续 |
| 分叉山脊 | 短脊、块体 | 分叉节点及支脊朝向 |
| 支脊/山肩 | 楔体、短脊 | 从主山体向外降低 |
| 峡谷 | 岩壁、楔体、可选峰体 | 对向山体、收放、转折与连续留白 |
| 错位峡口 | 岩嘴、岩壁 | 两侧前后错位、绕行空间 |
| 一线天 | 高岩壁、岩鳍 | 狭长净空、上下尺度与入口出口 |
| 曲折峡谷 | 弧脊/短岩壁、岩嘴 | 分段朝向变化、转角退让 |
| 分叉峡谷 | 岩壁、中央岩嘴 | 主谷与支谷连接处留白 |
| 宽谷 | 山肩、矮冠峰 | 两侧退让、宽阔谷底 |
| 盆地 | 圆丘、山肩、短脊 | 环绕低处，按需要保留出口 |
| 围合岩谷 | 岩壁、冠峰 | 围合与开口位置 |
| 崖壁 | 厚岩壁、基岩 | 明确陡面及背侧支撑 |
| 阶梯崖 | 平顶岩、岩壁 | 多层退台，层间高差 |
| 弧形崖 | 弧脊/短岩壁 | 弧向连续，内外侧区分 |
| 海蚀崖构图 | 岩壁、岩嘴、基岩 | 朝水侧陡壁和退让；水体由水模块提供 |
| 台地 | 平顶岩、岩壁、楔体 | 连续承托区及周缘落差 |
| 孤立桌山 | 平顶岩、厚岩壁 | 独立高台、明显周缘 |
| 多级台地 | 平顶岩、楔体 | 顶面层级与前后退让 |
| 崖侧岩台 | 平顶岩、楔体、岩壁 | 岩台伸出，保留承托与侧面空间 |
| 突出岩嘴 | 楔体、冠峰/岩壁 | 朝指定方向突出、后部连接 |
| 岩鳍群 | 薄板/岩鳍 | 多片朝向关系及片间留白 |
| 岩门/石拱 | 两侧块体、盖板/脊体 | 支点与上跨体，门洞净空；结构可实现性另验 |
| 岩棚/浅洞口 | 岩壁、盖板、块体 | 下方空间和上方支撑；不等于完整洞穴系统 |
| 碎岩坡/岩屑带 | 小块体、楔体 | 从主体向外变小、变疏；与通行区分开 |

这是扩展目录，不是本轮已实现的32种生成器。能表达某类结构不等于能随机生成其中任意优美实例。完整洞穴、多层穿插等拓扑需要显式空腔/连接关系；不能仅靠增加正体积 OBB 和标签保证。

## 统一组合能力，而不是为每种地貌复制生成器

1. 放置与变换：位置、独立尺寸、旋转和底高。
2. 排列：沿短骨架延展、成簇、环绕、分叉；间距依据通过时间/单岩展示节奏配置。
3. 接合：搭接、并排、上下承托、高端接低端；记录哪些面或体量承担连接。
4. 留白：通道、缺口、低口上方净空、观景方向、水系统授权域，各自独立保存。
5. 体量节奏：主次高度、宽窄、前后错位、稠密与稀疏；不能让随机摆放承担这些职责。

不新建对用户显示的最大OBB。地貌虚线范围仍由最终原子OBB投影并集生成，孔洞和多片范围保留。三维净空不能只看二维占地：岩门投影可能覆盖地面通道，但其上跨体底高决定下方是否能通过。

## 2026-09-16：形状特征约束落实到交互研究台

修正所有原子共用收窄层算法的问题：冠峰、尖塔、岩壁、台地、山肩、裙边采用不同归一化组成规则及默认米制尺寸。冠峰与尖塔在交互目录中拆分，旧合并类型只保留兼容。ShapeRules.ts 检查实际输出：尖塔高/最大底边至少1.5、顶端不超过底部18%、逐层收窄；冠峰保留30%–65%冠顶；岩壁宽度不小于厚度且宽顶延展；台地顶面投影至少55%；山肩/裙边高端偏向一侧，裙边高度不超过宽度25%。这些是可调整的阶段一白盒标准，不是自然地质定律或完整美术验收。形状区间显示在面板中，违反规则时保留上一有效图形并显示原因。

4项回归测试通过，包括默认地貌、原子区别、尖塔退化、裙边过高/居中失败；类型检查通过。浏览器确认尖塔默认20×16×60米，将高度降至4米时明确拒绝并保留60米有效图形。landform-interactive.html已重新生成，保持单文件离线。


## 2026-09-16：取消原子语义拒绝，收敛地貌组合

本节取代此前交互研究台的形状特征硬约束：原子名称仅为初始形状预设，修改高度、顶宽或偏移不会因“不像尖塔/裙边”被拒绝；仅保留有限数值与研究尺度边界。ShapeRules 不再参与交互生成。顶部比例直接控制顶层宽度，中间层连续插值。普通块体没有收窄参数，相关控件隐藏。

地貌入口暂收敛为主次峰群、连续山脊、曲折峡谷、退台高地四种；取消地貌主形状选择，隐藏原子参数，使用地貌自己的形状组合与小幅确定性轮廓变化。高度、开阔、弯曲、主次变化和尺度参数只在有效时显示。旧12组合不再列入当前交互页，旧静态目录不代表当前实现。新增回归检查：隐藏原子参数不改变地貌，保留的地貌参数改变OBB输出。美观程度仍需用户判断，未迁移到正式世界规划器。
