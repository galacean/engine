# 岚湾岛 · Water Island

独立入口：`/demos/water/island/`。Gallery 名称：**Water Island · 联合水体**，位于首页 Water 分类，菜单路由为 `/#water/island`。

场景实现位于 `demo/island/`；页面入口和 Gallery 元数据位于 `island/`，与其他 Water 案例采用相同的发现机制。

从仓库根目录运行 `pnpm --dir world dev --host 127.0.0.1 --port 5198 --strictPort`。编辑源位于 `world/gallery`；`world/.materialized/engine/world-gallery` 是生成的运行副本。已有服务运行时不要并行调用会重新同步整个 Gallery 的包装脚本。

## 场景与所有权

`WaterIslandPreset.ts` 定义固定水系、Bezier 湖岸、河流高程和宽度、七个连接口与七个镜头。默认景观 seed 为 1729，不改变水体几何、水位和拓扑。

- 西岸：west-river → ocean。
- 东岸：east-river → estuary-lake ↔ ocean。
- 中央：upper-river → main-lake → outlet-river → ocean；主湖含偏心小岛。
- 西北：独立 upland-lake，水位 +9 m。
- 西南：lagoon ↔ ocean。

`WaterIslandTerrain.ts` 一次生成 513 × 513 的统一高度快照。湖盆、河槽和开口先合成；各水体随后只读取地形。显示网格、局部裁剪和 Ocean 512 × 512 近岸数据遵循同一三角插值规则。`WaterIslandBodies.ts` 提供原生 Lake、River 和 Ocean Source，所有实例共享一个 `WaterSceneRuntimeHost`。

`WaterConnectionV1` 使用世界 XZ 接合线。第一侧负责负半平面，第二侧负责正半平面和接合线本身。编译器校验水位差不超过 1 cm、床面淹没、每体最多四个连接口，并生成可序列化的覆盖与过渡输入。这一版针对固定、平直、无重叠的连接走廊；连接水体要求保持世界原始变换。改变布局需要重新编译整个组合。

覆盖裁剪使用两侧源范围的交集和接合线，与视觉过渡长度分离。连接河流查询使用原生网格三角形，Ocean 排除区域使用原生河带的斜接边界，避免圆形端帽与弯角近似造成重复归属。

真实岸距从统一地形的水陆交界三角形提取，生成两侧共享的 65 × 65 采样数据。CPU 和 GPU 使用相同的 16 位量化、双线性插值和边缘混合，不把接合矩形侧边当作岸线。运行时为接合材质一次上传岸距图集，并在失败及销毁时随材质释放。三类 Backend 的原生 Forward/SSR/Ocean 远景路径消费连接输入；Lake/River 查询同时裁剪归属。交界附近衰减位移、法线和不一致的光学响应，海洋连接侧过渡到环境反射。Ocean 的静态归属同时排除其他水体的独占区域，仍没有新增物理查询能力。

## 素材和展示模式

`WaterLandscapeAssets` 是从原 Lake 提取的共用资源所有者；模型、KTX2 与素材清单保持一份。地形和景观布局分别由案例自己的文件负责。景观最多 90 棵树、180 株蕨类、220 个石块，按岸距、水深、坡度、成组采样和间距约束生成。地表分区纹理使用线性数据空间，seed 只参与景观及材质噪声。`WaterIslandLook.ts` 注册案例自己的 Look 变体。

DevTools 默认收起。可以选择水体、镜头，切换显示和动画。`presentation` 在创建调试 Session 时移除修改几何与导出 Draft 的能力；没有水位、控制点、重生成、JSON 导入和编辑会话。暂停后可记录固定动画时刻的截图；恢复按钮继续使用场景时间。
